## 강의는 어떤 내용이었나

제스테로 강사가 2026-05-26 진행한 지피터스 22기 2주차 실습 세션이다. 지난 기수에 이어 업그레이드된 내용으로, Claude.ai 데스크탑 앱의 **코어크(Coder)** 기능을 직접 써보는 실습 중심 강의다. 클로드 코드가 부담스러운 수강생도 코어크로 먼저 시작할 수 있도록 쉬운 진입 경로를 보여줬다.

실습은 크게 세 파트로 나뉜다. 첫 번째는 메시(messy) 폴더 정리, 두 번째는 영수증 이미지 OCR 정리, 세 번째는 미팅 노트 정리다. 후반부에는 Claude in Chrome 확장과 Play MCP를 연결해 웹 크롤링·카카오톡 연동으로 이어지는 자동화 구조를 소개했다.

| 3가지 원칙 | 전용 폴더 / 데스크탑 앱 + Pro 플랜 / 복사본 작업 + 승인 필수 |

## 0. 한눈에 보는 클로드 코어크 실습 흐름

1. 클로드 데스크탑 앱을 다운로드하고 Pro 플랜 여부를 확인한다.
2. 실습용 전용 폴더를 만든다 (바탕화면 전체 권한 주지 말 것).
3. 원본 파일은 따로 보관하고 복사본을 실습 폴더에 넣는다.
4. 코어크 하단 폴더 아이콘 → 다른 폴더 선택 → 실습 폴더 지정 → 허용.
5. 프롬프트를 구체적으로 3~4줄 이상 입력하고 실행한다.
6. 권한 요청이 뜨면 하나씩 확인하며 승인한다.
7. 결과물이 실습 폴더 안에 만들어졌는지 확인한다.
8. 필요하다면 Claude in Chrome 설치 → Play MCP 연결로 웹 자동화를 확장한다.

## 1. 클로드 코어크란 무엇인가

클로드에는 세 가지 형태가 있다.

- **클로드 바닐라**: 일반 채팅. 질문하고 답변 받는 방식.
- **클로드 코어크**: 지정한 로컬 폴더에 직접 접근해 파일을 생성·편집·정리하는 도구. 자연어 명령으로 결과물을 만든다.
- **클로드 코드**: 실제 코딩을 하는 전문 도구. CLAUDE.md 같은 지침서를 읽고 코딩한다.

> 코어크는 바닐라와 클로드 코드 사이 중간쯤에 있다. 큰 지침 없이 자연어로 결과물을 만드는 게 주 원칙이다.

**코어크를 쓸 수 있는 조건**:
- 클로드 데스크탑 앱 설치 (웹버전 아님)
- Pro 이상 구독

---

## 2. 코어크 사용 전 반드시 지켜야 할 3가지 원칙

**1. 전용 작업 폴더 지정**

바탕화면이나 전체 폴더에 접근 권한을 주면 내가 원하지 않는 변형이나 삭제가 일어날 수 있다. 항상 실습 전용 폴더를 만들어서 그 폴더만 지정한다.

**2. 클로드 데스크탑 앱 + Pro 플랜**

클로드 웹사이트에서 사용하는 게 아니라, 데스크탑 앱을 따로 설치해야 한다. Pro(또는 Max) 플랜 이상이어야 코어크 탭이 활성화된다.

**3. 복사본으로 작업 + 승인 건너뛰지 말 것**

중요한 원본은 따로 보관하고 복사본으로 작업한다. 권한 요청이 뜨면 처음에는 "항상 허용"이 아닌 **"허용"**으로 하나씩 확인하며 진행한다. 나중에 익숙해지면 자동 승인을 설정할 수 있다.

---

## 3. 실습 1 — 메시(Messy) 폴더 정리

### 폴더 지정 방법

코어크 화면 하단 왼쪽 플러스(+) 아이콘 옆에 **서류 뭉치 모양 아이콘**이 있다. 이걸 누른다.

1. 다른 폴더 선택 클릭
2. 정리할 폴더 클릭 (예: messy 폴더)
3. **폴더 선택** 버튼 클릭
4. 권한 요청 창 → **허용** (항상 허용 아님)

이 방식은 클로드 코드에서 첫 작업 폴더 지정하는 방식과 똑같다. 코어크에 익숙해지면 클로드 코드를 쓸 때도 도움이 된다.

### 프롬프트 작성 팁

> "정리해줘"처럼 모호하게 쓰면 삭제로 오인식할 수 있다. "파일을 유형별·날짜별로 분류해줘"처럼 구체적으로 3~4줄 이상 써라.

- 단순 파일명 변경·분류 작업은 **Haiku 모델**로도 충분하다. (추론 능력이 덜 필요)
- 여행 사진처럼 수백 장을 날짜·장소별로 분류하는 것도 같은 방식으로 할 수 있다.

---

## 4. 실습 2 — 영수증 OCR 정리

영수증 이미지가 든 폴더(receipt)를 지정하고 프롬프트를 입력하면, 코어크가 이미지를 읽어(OCR) 엑셀 보고서로 만들어준다.

> 얘가 스타벅스를 만들어줘서 깜짝 놀랐어요. 영수증 다 만들어왔는데.

**활용 상황**:
- 자영업자나 소규모 사업체에서 영수증 무더기를 한번에 정리
- 5월 종합소득세 신고 시 영수증 취합

**다른 AI와 차이점**:

| | 클로드 코어크 | 일반 AI 서비스 |
|---|---|---|
| 이미지 인식(OCR) | 있음 | 대부분 있음 |
| 결과를 엑셀로 저장 | 내 컴퓨터에 직접 생성 | 다운로드 별도 필요 |
| 업로드·다운로드 과정 | 없음 (로컬 직접 작업) | 파일 업로드 → 다운로드 |

OCR 품질 체감 순위 (강사 개인 의견): GPT-4o Image > Claude > (Gemini 2.5 출시 후 변동 예정)

---

## 5. 실습 3 — 미팅 노트(회의록) 정리

미팅 노트 폴더를 지정하고 프롬프트를 입력하면 회의 기록을 정리한 문서를 만들어준다. 강의 자료 PDF에 관련 프롬프트 예시가 포함되어 있다.

**활용 상황**:
- 회사에서 회의 정리를 담당하는 막내 직원 업무 자동화
- 여러 회의 기록을 통일된 형식으로 취합

**주의사항**: 코어크는 PPTX나 엑셀 같은 바이너리 파일은 내부를 수정하는 게 아니라 **새 파일을 만드는 방식**으로 작동한다. 마크다운(.md)이나 JSON 같은 텍스트 친화적인 파일은 내부 수정도 가능하다.

## 6. 심화 — Claude in Chrome + Play MCP 연결

### Claude in Chrome

크롬 브라우저에 설치하는 확장 프로그램. 이걸 설치하면 클로드가 크롬을 직접 제어할 수 있다.

**설치 방법**:
1. 크롬 오른쪽 상단 ··· 클릭 → 확장 프로그램 → 확장 프로그램 관리
2. **Claude in Chrome** 검색 후 설치
3. Pro 플랜 이상에서만 사용 가능 (Microsoft Edge도 가능)

**설치 후 가능한 것**:
- 웹 크롤링 (권한이 허용된 사이트)
- 반복 워크플로우 자동화
- 코어크나 클로드 코드에서 "검색해줘"라고 자연어로 명령하면 Claude in Chrome이 자동 호출됨

### Play MCP

[playmcp.com](https://playmcp.com)에서 설치. 카카오·네이버 등 국내 서비스와 클로드를 연결해주는 MCP 모음집이다.

**활용 예시**:
- 카카오맵 MCP: 주소 입력 → 가까운 지하철역 찾기
- 카카오톡 나에게 보내기: 크롤링 결과를 카카오톡으로 자동 보고
- 특정 해시태그 인플루언서 조회 (단, 인스타그램·X는 유료 API 필요)

**API 장벽 요약**:

| 서비스 | 무료 API | 비고 |
|---|---|---|
| 카카오 | 있음 | 국내 서비스 중 가장 무료 범위 넓음 |
| 네이버 | 일부 무료 | 일부 정보 접근 가능 |
| 인스타그램 | 유료 | 막혀있음, 돈 내야 |
| X(트위터) | 유료 | API 유료화됨 |

## 7. MCP 개념 정리 + 실시간 웹 가능한 LLM

> MCP가 앱의 미니버전이라기보다는 앱에 들어있는 빅데이터나 접근 권한이나 어떤 그런 것들에 대한 모음집 같은 거라고 생각합니다.

**실시간 웹 접근이 가능한 LLM 비교**:

| LLM | 실시간 웹 | 방법 |
|---|---|---|
| Google Gemini | 기본 지원 | 기본 탑재 |
| Perplexity | 기본 지원 (고가 플랜 더 강력) | 기본 탑재 |
| Claude | Claude in Chrome 설치 시 가능 | 확장 프로그램 |
| ChatGPT | 제한적 | 기본은 훈련 데이터 컷오프까지만 |

MCP 설치 후 클로드 코어크 또는 클로드 코드에서 사용 가능. MCP를 통해 수집한 웹 정보는 **출처를 밝히라는 프롬프트를 쓰면 할루시네이션이 거의 없다**.

## 8. 자주 막히는 곳

| 증상 | 대응 |
|---|---|
| 코어크 탭이 보이지 않는다 | 클로드 웹사이트가 아닌 **데스크탑 앱**을 설치했는지 확인. Pro 이상 플랜인지 확인. |
| 맥에서 코어크 로그인이 안 된다 | 오래된 버전이 남아있을 수 있음. 완전히 삭제 후 재설치. |
| 폴더 지정 화면(서류 뭉치 아이콘)이 안 보인다 | 코어크가 아닌 바닐라(일반 채팅)를 열었을 가능성. 코어크 탭으로 다시 들어간다. |
| 파일이 삭제됐다 | "정리해줘"처럼 모호한 프롬프트가 원인. 원본 복사본 보관을 항상 선행. 다음부터는 3~4줄 구체적 프롬프트 사용. |
| 실수로 삭제한 파일을 되돌리고 싶다 | 휴지통 확인. 없는 경우도 있으니 예방(복사본 보관)이 최선. |
| PPTX나 엑셀을 수정해달라고 했는데 새 파일이 만들어진다 | 정상 동작. 코어크는 바이너리 파일을 내부 수정하지 않고 새로 생성한다. 마크다운·JSON은 내부 수정 가능. |
| Claude in Chrome에서 특정 사이트 크롤링이 안 된다 | 해당 사이트 API 정책 문제. 인스타그램·X는 유료 API가 필요. 카카오·네이버는 무료 범위 내에서 가능. |
| 코어크가 느리다 | 정상. 특히 코어크는 처리 속도가 빠르지 않음. 단순 분류 작업은 Haiku 모델로 전환하면 빨라진다. |
