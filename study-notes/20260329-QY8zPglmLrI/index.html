내가 모를 만한 것 / 처음 보는 것

  • Claude Mythos — Anthropic이 개발 중인 완전 새로운 모델 등급 이름(유출된 코드명). Opus 위에 새 티어.
  • Capybara — Mythos보다 한 단계 아래지만 기존 Opus보다 크게 뛰어난 또 다른 유출 모델명.
  • Spurred (OpenAI 내부 프로젝트) — OpenAI가 개발 중이라는 차세대 모델 코드명. 업계 판 자체를 바꿀 수 있다고 평가.
  • ARC AGI 3 — ARC Prize 팀의 3세대 벤치마크. 첫 시도 성공률로 진짜 지능 측정. 용어노트 AGI 측정 기준.
  • OpenCode — "Codex"와 별개로 언급된 오픈소스 계열 코딩 에이전트 도구. Auto mode 도입으로 매번 권한 확인 없이 안전 작업 즉시 실행.
  • Voxtral — Mistral AI의 오픈웨이트 TTS 모델 이름.
  • Operon — 언급만 됨 (생물학 연구용 Claude Desktop 전용 에이전트 앱의 이름으로 추정).
  • Kimi K 2.5 — 문제가 된 오픈소스 모델. Cursor Composer 2의 실제 베이스 모델로 드러남.
  • ElevenLabs 에이전트 퍼스트 전환 — 기본값을 비대화형(non-conversational)으로 바꾸고, 대화형은 human-friendly 플래그 뒤로 숨김.

화자의 디테일 (놓치기 쉬운 포인트)

  1. Claude Mythos의 출시 속도 — Anthropic은 오남용·보안 위험을 우려해 천천히 출시할 계획이라고 명시. Fortune 보도 기준으로 현재 Opus와 "비교조차 안 될 정도"라고 묘사됨.
  2. Capybara 위치 — Mythos보다 한 단계 아래지만, 이미 오퍼스보다 완전히 새로운 등급(Tier). 소폭 업그레이드가 아님.
  3. GLM 5.1 속도 문제 — 벤치마크는 Opus 수준에 근접했으나 "속도가 엄청 느리다"고 화자가 직접 지적. 실무 투입 시 레이턴시 고려 필요.
  4. GLM 5.1 프론트엔드 인상 — 화자가 직접 생성한 랜딩 페이지 데모를 보여줌. 동적 애니메이션·타이포그래피·구조 코드 구현이 "꽤 깔끔하다"고 평가.
  5. Gemini 3.1 Flash Live 개발 기간 — 모델·인프라·개발자 경험까지 1년 이상 다듬었다고 강조. 단순 버전 업이 아님.
  6. Claude Code 세션 제한 강화 — 수요 폭증으로 Free·Pro·Max 구독자 모두 피크 시간대에 5시간 세션 제한 더 강하게 적용. 주간 한도는 유지되지만 평일 피크에 더 빨리 한도에 걸림.
  7. Cursor Composer 2 정체 — 커서가 "자체 최전성급 모델"이라고 주장했으나 사용자 분석 결과 Kimi K 2.5 오픈소스 모델의 파인튜닝 버전임이 드러남. 출처를 명시하지 않아 큰 논란.
  8. Sora(Solar) 종료 — 화자가 "Sora"라고 했지만 맥락상 OpenAI의 영상 생성 모델 Sora가 아닌 Solar 앱 종료 이야기. 크리에이터 배포·커뮤니티 활동 중단 예정. 팀은 작업물 보존 방법을 추후 안내 예정.
  9. ARC AGI 3 다음 단계 — 현재 인터랙티브 환경 → 다음 단계는 실제 상용 비디오 게임 환경에서 AI 에이전트 테스트.
  10. 화자 개인 의견 — "앞으로 2년 안에 자동화될 거라고 본다"며 Claude Mythos가 그 흐름에 큰 역할을 할 것이라고 예측.

1. Claude Mythos / Capybara 유출

Anthropic의 다음 모델 2종이 대규모 유출로 드러났다.

  • Mythos: 완전히 새로운 등급. 기존 Opus 위의 새 티어.
  • Capybara: Mythos보다 한 단계 아래지만, 역시 Opus를 크게 상회하는 완전 새로운 등급.
  • 주요 개선 영역: 코딩 성능, 학술적 추론, 사이버보안 능력 대폭 향상.
  • Fortune 보도: 이미 접근한 사람이 나왔으며, 현재 Opus와 비교조차 안 될 수준. "능력 자체가 위험"하다는 표현.
  • Anthropic 대응: 오남용·보안 위험 우려로 천천히 출시 계획.
  • 출시 순서 루머: Opus 5 또는 Sonnet 5가 먼저 나온 뒤, 유출된 2종이 순차 공개될 수 있음.
  • 화자 해석: 마케팅용 의도적 유출일 가능성도 있음 — 기대감과 긴박감 조성, 경쟁 우위 포지셔닝.

OpenAI도 내부적으로 Spurred 모델 개발 중. 업계에서는 AI 분야를 한 단계 끌어올릴 수 있다고 평가.

2. GLM 5.1 — 오픈소스 에이전트 모델

GLM팀(Zhipu AI)이 GLM 5.1을 공개. 오픈소스 에이전틱 모델 중 가장 진보한 축.

  • 특징: 멀티스텝 긴 작업 처리에 특화, 지시 따르기 개선, 가격 저렴.
  • 벤치마크: 45.3점 (Opus 47.9점에 근접 — "상용 모델에 꽤 가까워진 수치").
  • 단점: 속도가 엄청 느림.
  • 강점: 웹사이트 UI·프론트엔드 결과물이 인상적. 동적 애니메이션, 타이포그래피·구조 코드 구현 수준 높음.
  • 의미: 프론티어 AI와의 격차를 빠르게 좁히고 있는 오픈소스 모델.

3. Gemini 3.1 Flash Live

Google DeepMind가 공개한 실시간 멀티모달 모델.

  • 설계 목적: 음성·비전 에이전트 개발 전용.
  • 개발 기간: 모델 자체, 인프라, 개발자 경험까지 1년 이상 다듬음.
  • 개선: 품질 향상 + 안정성 증가 + 지연 대폭 감소.
  • 데모: 음성으로 앱 코드에 "마이크 이미지 크게 바꿔줘", "배경에 노란색 물방울 무늬 넣어줘" 같은 명령으로 실시간 UI 수정.

4. Codex 플러그인 생태계

OpenAI가 Codex에 플러그인을 도입하며 완전한 실행 환경으로 진화.

  • 기존: 프롬프트 입력 → 답변 반환. 도구가 따로 놀았음.
  • 이후: 플러그인으로 완전한 실행 환경. 이미 만들어진 실행 가능한 AI 워크플로 갤러리 제공.
  • 예: iOS앱 만들기, 데이터셋 분석, 보고서 생성, 발표 자료 제작.
  • 특징: 워크플로를 앱 안에서 한 번에 실행, 수정, 확장 가능. 매번 처음부터 시작 불필요.
  • 의미: Codex가 단순 도구 → AI 개발 플랫폼으로 진화. Claude Code와의 직접 경쟁 격화.

5. ARC AGI 3

ARC Prize팀이 새로운 벤치마크를 공개.

  • 핵심 설계: 첫 시도(one-shot)에서 문제 해결해야 함. 사전 학습·힌트 없음.
  • 결과: 사람 100% 해결 vs AI 사실상 1% 미만.
  • 과적합 방지: 패턴 암기로 가짜 지능 흉내 내지 못하도록 설계.
  • 인터랙티브 환경: 에이전틱 출원(agentic output) 테스트.
  • 다음 단계: 실제 상용 비디오 게임 환경 — AI가 복잡한 디지털 세계에서 행동·적응·작업.
  • 화자 평가: "좋은 신호다 — 처음으로 진짜 지능을 제대로 추적할 수 있는 벤치마크".

6. Claude Code 업데이트

최근 두 가지 주요 업데이트.

Claude Auto Fix: - CI 실패를 원격에서 자동 수정. - PR 리뷰 코멘트 자동 반영. - PR 상태를 계속 초록(머지 가능) 상태로 유지. - 원격 실행이므로 코드 푸시 후 자리를 비워도 됨.

세션 제한 강화: - 수요 폭증으로 Free·Pro·Max 구독자 피크 시간대에 5시간 세션 제한 더 강하게 적용. - 주간 한도는 유지. 평일 피크 시간에 더 빨리 한도에 도달.

7. 기타 업데이트

OpenCode Auto Mode: - 더 이상 매 동작마다 권한 확인 불필요. - 안전한 작업 즉시 실행 / 위험한 작업 차단. 마찰 줄이고 통제 유지.

ElevenLabs 에이전트 퍼스트 전환: - 기본값이 비대화형(non-conversational)으로 변경. - 에이전트·자동화·워크플로에 최적화. - 대화형 경험은 human-friendly 플래그 뒤로 분리.

Voxtral TTS (Mistral AI): - 오픈웨이트 TTS 모델. 9개 언어·방언 지원. - 감정 표현 있는 현실적 음성, 거의 즉시 오디오 생성. - 새 목소리 적응 용이.

Operon (Anthropic): - Claude Desktop용 생물학 연구 전용 에이전트 앱 개발 중(미공개). - 여러 세션 관리, 산출물 관리, 특화 스킬 활용 가능. - "과학자를 위한 Cursor" 개념.

Solar 앱 종료: - 크리에이터의 배포·커뮤니티 활동 중단 예정. - 팀은 작업물 보존·내보내기 방법 추후 안내 예정. - OpenAI가 남은 연산 자원을 Spurred 개발에 집중하는 것으로 해석.

Cursor Composer 2 논란: - Cursor가 "자체 최전성급 코딩 모델"이라 주장. - 사용자 분석 결과: 실제는 Kimi K 2.5 오픈소스 모델의 파인튜닝 버전. - Cursor가 출처를 명시하지 않아 정체를 두고 큰 혼선 발생.

전체 전사 펼치기

이건 진짜 역대급으로 미친 AI 한 주라고 할 만합니다. 바로 어제 Anthropic에서 대규모 유출이 있었고, 10조 파라미터 모델이 공개됐는데 지금까지 만들어진 가장 강력한 모델이라고 주장하고 있습니다. GLM 5.1도 지금까지 나온 오픈소스 에이전팅 모델 중 가장 진보한 것 중 하나를 공개했습니다. Google DeepMind가 Gemini 3를 공개했습니다. Gemini 3.1 Flash Live는 실시간 오디오 AI를 한 단계 더 끌어올리고 있습니다. Codex는 완전한 플러그인 생태계로 확장되면서 Claude Code를 정면으로 겨냥하고 있습니다. 게다가 ARC AGI 3는 AI 시스템의 지능을 평가하는 기준까지 한 단계 끌어올렸습니다.

Claude Mythos / Capybara 유출

가장 큰 소식부터 시작합니다. 대형 유출로 Anthropic의 다음 모델 2개가 드러났습니다. 하나는 완전히 새로운 등급의 Claude Mythos입니다. 그리고 Capybara라는 모델도 함께 나왔습니다. 중요한 건 Capybara가 Mythos보다 한 단계 아래라고 알려졌지만, 이미 Opus보다 훨씬 위에 완전히 새로운 등급이라는 점입니다. Opus는 이미 Anthropic의 플래그십 모델이죠. 그러니까 이건 작은 업그레이드가 아닙니다. 완전히 새로운 최전선 티어입니다.

여기에는 코딩 성능 향상, 더 강한 학술적 추론, 그리고 놀라울 정도로 큰 사이버 보안 능력 향상이 들어갑니다. 이미 접근한 사람도 나왔습니다. 심지어 Fortune 보도에 따르면 이 모델은 현재 Opus와 비교조차 안 될 정도라고 합니다. 능력 자체가 위험합니다. 지금 우리가 가진 버전보다도 엄청난 도약입니다. 실제로 너무 강력해서 Anthropic은 오남용과 보안 위험을 우려해 천천히 출시할 계획이라고 합니다.

제 개인적인 의견으로는, 앞으로 2년 안에 자동화될 거라고 보는데 이 모델이 그 흐름에 큰 역할을 할 겁니다.

이건 Anthropic만의 이야기가 아닙니다. OpenAI도 내부적으로 Spurred라는 모델을 개발 중이라고 하는데, 업계에서는 AI 분야를 한 단계 확 끌어올릴 수 있다고 보고 있습니다.

다시 Anthropic 이야기로 돌아가면, 루머에 따르면 Opus 5나 Sonnet 5 같은 중간 버전이 먼저 나올 수도 있고, 그 다음에는 이번에 유출된 두 모델이 순차적으로 공개될 수도 있습니다. 몇 달에 걸쳐 천천히 출시할 수도 있습니다. 솔직히 이건 전략적인 포지셔닝일 수도 있습니다 — 기대감과 긴박감을 키우고 AI 경쟁에서 우위를 잡으려는 마케팅용 유출일 수도 있습니다.

이게 중요한 이유는 솔직히 2026년이 AI 판을 완전히 바꿀 해가 될 가능성이 크기 때문입니다. OpenAI는 이미 일부 조직 이름도 배포 쪽으로 바꿨고, GPT-5도 기대를 모으고 있습니다.

GLM 5.1 오픈소스 에이전트 모델

GLM팀이 Zhipu AI의 오픈소스 에이전틱 모델인 GLM 5.1을 공개했는데, GLM 5보다 확실히 크게 좋아졌습니다. 이 모델은 에이전틱 동작에 집중해서 긴 작업을 더 잘 처리합니다. 지시도 더 잘 따릅니다. 여러 단계 작업에서도 더 안정적이고 가격도 꽤 저렴합니다. 벤치마크에서는 45.3점을 받아 Opus의 47.9점과 꽤 비슷했습니다. 이건 정말 근접한 수치로 상용 모델에 꽤 가까워졌다는 뜻입니다.

핵심은 바로 이겁니다. 프론티어 AI와의 격차를 빠르게 좁히고 있다는 점입니다.

한 가지 아쉬운 점은 속도가 엄청 느리다는 건데, 웹사이트 UI 쪽 결과물은 이 모델이 정말 놀랍습니다. 제가 GLM 5.1로 생성한 랜딩 페이지를 보면, 프론트엔드 능력은 정말 인상적이라고 말할 수 있습니다. 동적인 움직임도 꽤 잘 처리했습니다. 다양한 타이포그래피와 구조가 전부 코드로 잘 구현돼 있습니다.

Gemini 3.1 Flash Live

Google DeepMind가 새로 공개한 Gemini 3.1 Flash Live 소식입니다. 이건 음성과 비전 에이전트를 만들기 위해 설계된 완전 새로운 실시간 멀티모달 모델입니다. 단순한 소폭 업그레이드가 아닙니다. 모델 자체, 인프라, 개발자 경험까지 1년 넘게 다듬었습니다. 품질은 더 좋아지고, 안정성은 높아지고, 지연은 훨씬 줄어서 실시간 AI에 딱 필요한 수준입니다.

실제 데모: 음성으로 "마이크 이미지를 더 크게 바꿔줘", "배경에 노란색 물방울 무늬를 넣어줘" 같은 명령으로 앱 코드를 실시간으로 수정.

Codex 플러그인 생태계

OpenAI가 Codex에 플러그인을 도입한 꽤 인상적인 새 업데이트입니다. 이건 사람들이 코딩 에이전트를 실제로 쓰는 방식을 크게 바꿀 수 있는 변화입니다.

지금까지는 대부분의 AI 코딩 도구가 따로 놀았거든요. 프롬프트를 넣으면 답을 주고 끝나는 시기였고, Codex도 크게 다르지 않았습니다. 하지만 이제 플러그인이 생기면서 완전한 실행 환경이 됩니다.

이제 사용 사례를 살펴볼 수 있는데요 — iOS 앱 만들기, 데이터셋 분석, 보고서 생성, 발표 자료 제작 같은 실제 워크플로 갤러리를 볼 수 있습니다. 이런 워크플로를 Codex 앱 안에서 한 번에 실행할 수 있고, 수정하고 확장할 수도 있습니다. 이건 큰 진전입니다. Codex가 단순한 도구가 아니라 AI 개발 플랫폼처럼 느껴지게 만듭니다. 그리고 이건 분명 Claude Code나 다른 에이전트형 도구들과 직접 경쟁하게 될 변화입니다.

ARC AGI 3

지금 최고 모델들도 여기서 1%도 못 넘기는데, 나빠 보일 수 있지만 사실은 좋은 신호입니다. 처음으로 암기 말고 진짜 성과와 지능을 제대로 추적할 수 있는 벤치마크가 생겼기 때문입니다.

이건 인터랙티브 환경에서 에이전틱 출원을 테스트하는 새로운 벤치마크입니다. 첫 시도의 과제를 해결해야 합니다. 사전 학습이나 힌트도 없습니다. 사람은 첫 시도에서 100% 해결할 수 있습니다. 하지만 AI는 아직도 사실상 1% 아래에 머물러 있습니다. 이번엔 과적합을 막는 데도 큰 초점을 두고 있어서, 모델이 패턴만 외워서 가짜 지능을 흉내 내지 못하게 합니다.

다음 단계는 실제 상용 비디오 게임. 그러면 AI는 단순히 출원만 하는 게 아니라 사람처럼 복잡한 디지털 세계에서 행동하고, 적응하고, 작업할 수 있게 됩니다.

Claude Code 업데이트

최근 Claude Code에 몇 가지 새 업데이트가 있었습니다. 먼저 Claude Auto Fix를 도입했어요. 이 기능은 Claude에서 CI 실패를 자동으로 수정하고, 리뷰 코멘트도 반영하고, PR 상태를 계속 초록색으로 유지해줍니다. 이건 원격으로 돌아가니까, 코드를 푸시해두고 자리를 비워도 됩니다. 돌아오면 머지 준비가 된 PR이 생겨 있습니다.

또 수요가 너무 많아서 Claude Code가 피크 시간대에 Free·Pro·Max 구독자에게 임시로 5시간 세션 제한을 더 강하게 적용한다는 소식도 있습니다. 주간 한도는 그대로지만, 평일에는 이전보다 더 빨리 세션 제한에 걸리게 됩니다.

OpenCode도 이제 Auto Mode를 도입했습니다. 더 이상 계속 권한을 묻지 않습니다. 안전한 작업은 바로 실행되고, 위험한 작업은 차단됩니다. 전체적으로 마찰은 줄이면서 더 잘 통제할 수 있게 됩니다.

기타 업데이트

ElevenLabs가 이제 완전히 에이전트 퍼스트 방향으로 바뀌었습니다. 기본값이 비대화형이라, 에이전트와 자동화, 워크플로우가 훨씬 매끄럽게 쓸 수 있습니다. 반면 대화형 경험은 human-friendly 플래그 뒤로 들어갔습니다.

Mistral AI는 Voxtral TTS를 새로 공개했습니다. 자연스럽고 표현력이 뛰어나며 초고속 오픈웨이트 TTS 모델입니다. 9개 언어를 지원하고, 감정 표현이 살아있는 현실적인 음성을 내며, 거의 즉시 오디오를 생성할 만큼 지연도 낮습니다.

Anthropic이 Claude Desktop용 새 에이전트 Operon을 개발하고 있다는 소식입니다. 특히 생물학 연구를 위해 만들어졌습니다. 여러 세션을 만들고, 산출물을 관리하고, 특화된 스킬도 활용할 수 있습니다. "과학자를 위한 Cursor"라고 생각하면 됩니다.

Solar 앱이 곧 종료됩니다. 크리에이터들의 배포나 커뮤니티 활동도 멈추게 됩니다. 팀은 작업물 보존·내보내기 방법을 곧 안내할 예정입니다.

마지막으로 Cursor Composer 2 이야기를 하면, Cursor가 자신들이 최전성급 코딩 모델이라고 주장했습니다. 그런데 한 사용자가 이게 사실 Kimi K 2.5 모델이라는 걸 알아냈습니다. 오픈소스 모델인 Kimi K 2.5를 베이스로 파인튜닝한 것이었는데, 문제는 Cursor가 그걸 명확히 밝히지 않았다는 점입니다. 자체 모델을 학습한 것처럼 보였는데 실제로는 아니었던 것입니다.
