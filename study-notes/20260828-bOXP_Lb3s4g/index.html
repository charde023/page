Will AGI be one mind? Rich Sutton says no — Codex 버전

원작자 Rich Sutton · 업로드 2026-08-28 · 0.9분 · 원본 영상 ↗

먼저 읽는 쉬운 요약

처음 보는 사람을 위한 읽기 안내

영상 미시청 기준 · 약 1분 · 선수지식: 없음 이 부분만 읽어도 아래 중심 질문에 자기 말로 답할 수 있게 설명한다.

질문은 사람처럼 폭넓은 일을 배우는 인공지능(AGI)이 결국 모든 일을 해내는 하나의 정신과 하나의 가중치 묶음이 되느냐는 것이다. 답변은 “하나의 설계, 여러 정신”이다. 같은 기본 설계라도 서로 다른 환경에서 다른 경험을 하면 각 시스템이 다른 것을 배운다는 뜻이다.

근거로는 배울 것이 무한히 많다는 큰 세계 가설(Big-World Hypothesis)과, 같은 수준으로 복잡한 두 시스템은 서로를 완전히 모델링할 수 없다는 주장이 제시된다. 따라서 하나가 전부를 익히기보다 여러 시스템이 자기 경험에서 배우는 그림이다. 다만 이는 짧은 발화에서 제시된 논증이며, 전사만으로 검증된 정리나 실험 결과는 아니다.

여기까지만 이해하면 충분

  • 공통된 설계가 있다고 해서 모든 경험을 가진 하나의 정신만 존재해야 하는 것은 아니다.
  • 서로 다른 환경과 경험은 같은 설계의 시스템들을 서로 다른 정신으로 만들 수 있다.
  • “한 시스템은 모든 것을 배울 수 없다”는 결론은 영상 속 주장이며 별도 검증이 필요하다.

오늘 대답할 질문

왜 화자는 AGI의 미래를 ‘하나의 만능 정신’이 아니라 ‘하나의 설계에서 나온 여러 정신’으로 보는가?

한 장면으로 이해하기

같은 기본 설계로 만든 시스템 두 개가 서로 다른 환경에서 살아간다. 하나는 나뭇가지를 타는 경험을 배우고, 다른 하나는 우주선을 만드는 경험을 배운다. 설계는 같지만 축적한 경험과 배운 내용은 달라진다.

"한 시스템이 모든 환경의 모든 것을 배워야 한다" 문제
→ "같은 설계의 여러 시스템이 서로 다른 경험에서 학습한다" 작동 방식
→ "공통 설계는 유지되지만 서로 다른 여러 정신이 생긴다" 결과

비유와 깨지는 지점

같은 양식으로 만든 여러 권의 경험 노트

모든 노트가 같은 칸과 규칙을 사용하더라도, 각 노트에 서로 다른 경험을 적으면 내용은 달라진다. 공통 양식은 하나의 설계에, 각기 다른 기록은 여러 정신이 배운 내용에 대응한다.

비유가 깨지는 지점: 노트는 스스로 환경에 반응하거나 학습하지 않는다. 또한 이 비유만으로 한 시스템이 모든 것을 배울 수 없다는 주장이 증명되지는 않는다.

1. 원인

같은 설계로 만든 시스템들이 왜 서로 다른 정신이 된다고 보는가?

모범 답안 보기

각 시스템이 서로 다른 환경에서 서로 다른 경험을 하기 때문이다. 발화의 논리에 따르면 설계는 같아도 학습한 내용은 달라지므로 여러 개별 정신이 생긴다.

2. 대조

‘하나의 설계’와 ‘하나의 정신·하나의 가중치 묶음’은 어떻게 다른가?

모범 답안 보기

하나의 설계는 여러 시스템이 공유할 수 있는 기본 구조를 뜻한다. 하나의 정신이나 가중치 묶음은 모든 경험이 한 개별 시스템에 모인 상태를 가리킨다. 영상의 답변은 전자는 가능하지만 후자가 유일한 종착점은 아니라고 구분한다.

3. 적용

새 AI 시스템을 설계한다면, 하나의 범용 인스턴스와 같은 설계의 여러 인스턴스 중 무엇을 시험해야 할까?

모범 답안 보기

먼저 과제들이 같은 경험을 공유해야 하는지, 환경별 경험이 얼마나 다른지 정한다. 그다음 동일한 평가 과제와 총 시도 횟수로 단일 인스턴스와 복수 인스턴스를 비교한다. 영상의 주장을 결론으로 채택하지 말고 과제 성공률로 판단한다.

이번 글의 통찰

1. 통일해야 할 것은 정신이 아니라 설계일 수 있다

  • [원문] 답변자는 “하나의 설계”는 있을 수 있지만 “여러 정신”이 존재하며, 서로 다른 환경과 경험 때문에 각 시스템이 다른 것을 배운다고 말한다. 이어 배울 것이 무한히 많고 한 시스템은 모든 것을 배울 수 없다는 논거가 제시된다.
  • [해석] 범용성을 모든 경험을 한 시스템에 넣는 문제로만 보지 않고, 공통 설계가 다양한 환경에서 여러 학습 경로를 만들게 하는 문제로 다시 볼 수 있다.
  • [경계] 56초와 0.9분은 반올림하면 양립하므로 수치 충돌이 아니다. 그러나 전사에는 화자 이름이 없고, META 제목과 provenance는 Rich Sutton을 가리키는 반면 설명문은 복잡성 논거를 Khurram Javed의 이유라고 적는다. 따라서 전체 논증을 Rich Sutton 한 사람의 발언으로 확정할 수 없다. provenance도 원작자 연결을 ‘추정’이라고 밝힌다. 또한 “같은 복잡성의 두 시스템은 서로를 모델링할 수 없다”는 문장은 전사 안에서 증명되거나 실험으로 검증되지 않는다.

차드의 4렌즈

교육자 · 구조적 비유

  • 관련성: 같은 설명이나 수업 설계를 제공해도 학습자는 서로 다른 경험을 바탕으로 다른 것을 배울 수 있다는 구조와 닮았다.
  • 통찰: 공통 수업을 전달했다는 사실보다, 학습자가 새 사례를 자기 말로 설명하는지를 관찰해야 한다.
  • 질문/행동: 같은 개념을 서로 다른 사례 두 개에 적용하게 하고 설명의 차이를 확인한다.

사업가 · 영감

  • 관련성: 모든 환경을 하나의 운영 방식에 담을지, 공통 원칙 아래 환경별 운영 단위를 둘지 묻는 구조를 제공한다.
  • 통찰: APOM에 적용할 수 있는지는 아직 검증되지 않았다. 적용한다면 단일 통합 운영과 환경별 분리 운영 중 어느 쪽이 오류와 학습 비용을 줄이는지 비교할 가설로만 다룬다.
  • 질문/행동: 분리했을 때 성과가 좋아질 만큼 경험과 조건이 실제로 다른 업무가 있는가?

마케터 · 직접 전이

  • 관련성: 나뭇가지 타기와 우주선 만들기의 강한 대조가 “모든 일을 하는 한 정신”이라는 질문을 선명하게 만든다.
  • 통찰: 인상적인 장면은 주장을 기억하게 하지만 증거를 대신하지 않는다. 카피에서는 주장, 논거, 검증 결과를 구분해야 한다.
  • 질문/행동: 강한 대조 문장 뒤에 실제로 제시할 수 있는 검증 자료가 있는지 표시한다.

AI/SW 학습자 · 직접 전이

  • 관련성: 공통 설계와 개별 가중치, 단일 시스템과 복수 시스템을 구분하는 아키텍처 질문이다.
  • 통찰: 기술 이름보다 환경별 경험과 과제 성능을 기준으로 단일 인스턴스와 복수 인스턴스를 비교해야 한다.
  • 질문/행동: 동일한 총 시도 횟수에서 두 방식의 환경별 과제 성공률을 측정한다.

작은 실험 하나

  • 행동 1개: 서로 다른 모의 과제 두 개를 정하고, 단일 인스턴스와 같은 설계의 독립 인스턴스 두 개를 동일한 총 시도 횟수로 시험한다.
  • 측정 1개: 두 과제를 합친 전체 성공률
  • 중단 기준 1개: 독립 인스턴스 방식의 전체 성공률이 단일 인스턴스보다 높지 않으면 복수 인스턴스 방식의 확대를 중단한다.

# 섹션 요지
1 하나의 정신인가 모든 일을 하나의 정신과 가중치가 배울 것인지 질문한다.
2 하나의 설계, 여러 정신 공통 설계의 여러 시스템이 서로 다른 경험을 배운다는 답이 나온다.
3 제시된 한계 논거 배울 것이 무한하며 같은 복잡성의 시스템은 서로를 모델링할 수 없다는 주장이 이어진다.

1. 하나의 정신인가

질문자는 모든 일이 잘 풀렸을 때, 나뭇가지 타기부터 우주선 만들기까지 다양한 일을 하나의 정신과 하나의 가중치 묶음이 수행하게 되는지 묻는다. 이 대조는 AGI의 종착점을 단일한 만능 시스템으로 볼 것인지 확인하기 위한 장면이다.

2. 하나의 설계, 여러 정신

답변은 “하나의 설계”와 “여러 정신”을 구분한다. 같은 설계가 서로 다른 환경에 반응하고, 각 버전은 서로 다른 경험 때문에 다른 것을 배운다는 설명이다. 따라서 공통점은 기본 설계이고, 차이는 각 시스템이 축적한 경험과 학습 결과다.

3. 제시된 한계 논거

이어지는 논거는 다음 흐름을 가진다.

  1. 큰 세계에는 배울 것이 무한히 많다.
  2. 한 시스템은 무한히 많은 것을 모두 배울 수 없다.
  3. 세계에서 가장 큰 수준의 시스템 두 개가 같은 정도로 복잡하다면 서로를 모델링할 수 없다.
  4. 그러므로 하나의 시스템이 모든 것을 배우는 지점에는 도달할 수 없고, 여러 시스템이 각자의 경험에서 배우게 된다.

이 흐름은 발화자의 주장으로 보존해야 한다. 제공 자료에는 이를 뒷받침하는 실험, 수학적 정의 또는 독립적인 1차 근거가 없다.

수치·고유명사 대조

  • META의 길이 56초와 0.9분은 환산 및 반올림 범위에서 양립한다.
  • META 제목은 Rich Sutton의 답변으로 소개하고 provenance.creator도 Rich Sutton을 제시한다.
  • provenance.note는 원본 영상 연결을 확인하지 못해 화자 이름과 SNS를 기준으로 추정했다고 밝힌다.
  • META 설명문은 “하나의 설계, 여러 정신”이라는 답을 Rich Sutton에게, 두 시스템의 상호 모델링 논거를 Khurram Javed에게 연결한다.
  • 전사 본문에는 화자 이름표가 없으므로 각 문장을 누구에게 귀속할지는 제공 자료만으로 완전히 확정할 수 없다.
  • 하나, 둘, 여러, 무한히 많은 것은 각각 설계·시스템·정신·학습 대상에 사용되며, 이름 열거와 개수 사이의 불일치는 없다.

전체 전사 펼치기

모든 일이 순조롭게 진행된다면, 나뭇가지 사이를 오가는 법을 배우는 것부터 우주선을 만드는 일까지, 오늘 우리가 이야기한 다양한 일을 모두 해낼 수 있는 하나의 마음(single mind)을 상상하고 계신 건가요?

이 모든 일을 해낼 수 있는 하나의 마음과 하나의 가중치 집합(single set of weights)인가요?

하나의 설계(design)입니다. 마음은 여러 개가 될 겁니다.

알겠습니다. 그렇다면 서로 다른 환경에 반응하는 하나의 설계라는 말이군요. 그 마음의 서로 다른 버전들은 서로 다른 경험을 하기 때문에 서로 다른 것을 배우게 되고요.

이건 모든 것을 배울 수 있는 무한히 많은 것들이 존재한다는 대세계 가설(big-world hypothesis)로 다시 이어지는 것 같습니다. 따라서 하나의 시스템은 무한히 많은 것을 배울 수 없습니다.

이런 시스템이 두 개, 즉 세상에서 가장 큰 시스템 두 개가 있다면, 두 시스템이 서로를 모델링할 수 없다는 것은 자명합니다. 두 시스템의 복잡성이 동일하기 때문입니다.

그러므로 하나의 시스템이 모든 것을 배울 수 있는 지점에 도달하는 일은 결코 없을 겁니다. 여러 시스템이 각자의 경험을 통해 계속 학습하게 될 것입니다.
