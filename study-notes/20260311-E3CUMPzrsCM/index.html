프로젝트 생산성을 10배 높여주는 Claude Code 플러그인 10선

한 줄 요약

Claude Code 실전 사용자가 직접 쓰는 CLI·스킬 10가지를 소개하며, MCP보다 CLI가 항상 우선이라는 핵심 원칙을 강조한다.

내가 모를 만한 것 / 처음 보는 것

  • GSD (Get Sh*t Done) — Claude Code용 오케스트레이션 프레임워크. /gsd new project 명령으로 스팩 기반 단계 실행. 컨텍스트 윈도우 후반부 품질 저하 방지를 위해 각 단계마다 새 컨텍스트 + 서브에이전트 사용.
  • NotebookLM-PI — NotebookLM을 CLI로 조작하는 서드파티 도구. 공식 API 없음에도 리서치·팟캐스트·플래시카드 등 산출물 생성 가능.
  • Firecrawl — AI 에이전트 맞춤 웹스크래핑 CLI. 핵심 4가지 명령: scrape / crawl / map / search. 단순 스크래핑과 달리 AI가 맥락에 맞는 명령을 자동 선택.
  • Playwright CLI (playwright show 명령) — 헤드리스 실행 중에도 모든 브라우저 에이전트의 동작을 시각적 대시보드로 표시.
  • Excalidraw Diagram Skill — GitHub에서 레포 클론 후 프로젝트 스킬 디렉터리에 복사. 지식 디렉터리를 포인팅하면 콘텐츠를 읽고 자동으로 다이어그램 생성.
  • Supabase CLI — pgvector 포함 PostgreSQL DB + 인증을 로컬 개발 + 셀프호스팅 가능. MCP보다 CLI 버전 권장.
  • Vercel CLI + 에이전트 루프 — 변경 감지 시 자동 배포 상태 확인 루프 구성 가능.

화자의 디테일 (놓치기 쉬운 포인트)

  1. 화자 본인도 최근까지 Supabase MCP를 쓰고 있었음. 댓글로 지적받고 나서야 Supabase CLI 존재를 알았다고 고백 — "이 분야에서 매일 도구를 보는 내가도 따라가기 힘든 게 현실"
  2. MCP는 2024년 Anthropic이 만든 AI-데이터 연결 표준. 하지만 2026년 현재 Claude Code가 터미널 안에서 직접 실행되므로 CLI가 더 적합하다는 주장.
  3. Skill Creator는 Anthropic 공식 GitHub에 있으며, AB 테스트 기능으로 "스킬 적용 전/후" 성능 비교 가능 — 이전에는 감에 의존했음.
  4. Obsidian 사용 시 별도 CLI나 스킬 불필요. Obsidian 볼트 폴더에서 Claude Code를 열고 "마크다운 작성 시 Obsidian 규칙을 따르라"고만 말하면 됨.
  5. GitHub CLI는 Claude Code가 git/GitHub에 이미 능숙하므로 별도 스킬 없어도 충분히 작동 — 단, 필요하면 Skill Creator로 커스텀 스킬 직접 생성 가능.
  6. Excalidraw 스킬 제작자: Cole Medin (유튜브 채널 있음). 화자가 개인적으로 가장 아끼는 도구 중 하나로 꼽음.
  7. NotebookLM-PI는 로그인 시 터미널에서 notebooklm 실행 → 브라우저 팝업 → Google 계정 로그인 방식.
  8. Vercel CLI + 에이전트 루프 패턴: 프로젝트 변경 시마다 Vercel CLI 스킬을 호출해 배포 상태를 자동 확인하는 반복 루프 구성 가능.
  9. Playwright CLI의 playwright show 명령 — 영상에서 "딥다이브 영상에서 언급하지 않은 것"으로 특별히 언급.
  10. Firecrawl은 "Claude Code 내장 웹검색보다 확실히 한 단계 위"라고 명시.

1. Supabase CLI (vs MCP)

화자는 먼저 Supabase MCP 서버를 소개했다가 "사실 CLI를 써야 한다"고 방향을 틀었다. 이유는 두 가지:

  • CLI가 MCP보다 우수한 이유: Claude Code는 이제 터미널 안에서 실행된다. MCP는 터미널 밖에서 데이터 시스템과 연결하기 위해 만들어진 표준(2024)이지만, Claude Code가 터미널 내부에 있는 2026년에는 CLI가 더 직접적이고 오버헤드가 없다.
  • Supabase 사용 이유: PostgreSQL DB(pgvector 포함) + 인증(사용자 프로필, 데이터 분리)을 모두 처리. 무료 티어 넉넉함. 오픈소스 기반.
  • 설치: OS별 Supabase 공식 문서 참조. 또는 Claude Code에게 "Supabase CLI 설치해줘"라고 말하면 됨.
  • 스킬 연동: Claude Code 플러그인 마켓플레이스에 Supabase 공식 스킬 존재.

핵심 원칙: CLI와 MCP 중 선택 가능하다면 항상 CLI.

2. Skill Creator (Anthropic 공식)

Anthropic이 출시한 공식 스킬 생성·평가 도구. 화자가 "오늘 10개 중 가장 강력"이라고 꼽음.

  • 기능: 커스텀 스킬 생성 + 기존 스킬 수정/개선 + AB 테스트로 성능 측정
  • "스킬이 실제로 작동하는가"를 데이터로 확인 가능. 이전 버전 대비 현재 버전이 더 나은지 수치로 비교.
  • 설치: /plugin 입력 → 목록에서 Skill Creator 검색 → 설치
  • 사용: /skill-creator 명령 또는 자연어("스킬 크리에이터로 새 스킬 만들어줘")
  • 내부는 Anthropic GitHub의 Claude Code 스킬 섹션에 공개된 텍스트 프롬프트.

3. GSD (Get Sh*t Done) 프레임워크

Claude Code 위에 올라가는 오케스트레이션 레이어. 새 프로젝트를 체계적으로 시작할 때 사용.

  • 핵심 역할: 스펙 기반 개발 가드레일 제공. 각 기능/단계마다 새 컨텍스트 윈도우 + 서브에이전트 사용 → 컨텍스트 윈도우 후반부 품질 저하 방지.
  • 설치: GitHub에서 GSD 또는 Get Done 검색 → 한 줄 명령어.
  • 사용: /gsd new project → 플래닝 모드 시작. Claude Code가 "무엇을 만들 것인지" 상세히 파악한 뒤 단계적 실행.

4. NotebookLM-PI

NotebookLM을 Claude Code 터미널에서 사용할 수 있게 해주는 CLI 도구 + 스킬.

  • 공식 API 없음에도 동작. 리서치, 분석, 인포그래픽, 슬라이드덱, 플래시카드, 팟캐스트 생성 가능.
  • 거의 무료로 NotebookLM 기능 활용 가능 — 화자 리서치 워크플로우 핵심.
  • 설치: GitHub에서 명령어 복사 → 의존성 설치 → notebooklm 실행 → 브라우저 팝업에서 로그인.
  • 스킬 연동 필수: CLI 도구 설치 후 대응 스킬도 함께 설치.

5. Obsidian

개인 비서 용도로 Claude Code와 결합 시 강력. 마크다운 파일 간 연결 관계를 시각화하고 체계적으로 관리.

  • 별도 CLI·스킬 불필요. Obsidian 볼트로 지정한 폴더에서 Claude Code를 열고, "마크다운 작성 시 Obsidian 규칙 따르라"고 말하면 끝.
  • 적합한 상황: 대용량 마크다운 컨텍스트가 쌓이는 개인 비서 세계. 일반 코딩 프로젝트에는 큰 가치 없음.

6. Vercel CLI

배포 관리를 자연어로 처리. 무료 티어 훌륭함.

  • 설치: npm i -g vercel 또는 Claude Code에게 "Vercel CLI 설치해줘".
  • 스킬: Vercel 공식 웹사이트에서 스킬 제공.
  • 에이전트 루프 활용: 프로젝트 변경 시마다 Vercel CLI 스킬을 호출해 배포 상태를 자동 확인하는 루프 구성 가능. 새 에이전트 루프 기능과 궁합 좋음.

7. Playwright CLI

Microsoft 오픈소스 브라우저 자동화 도구. UI 테스트와 브라우저 에이전트에 최적.

  • 설치: Playwright CLI GitHub → 명령어 복사 → 의존성 설치 → playwright install skills 로 스킬 설치.
  • 사용 사례: UI 디자인 테스트, 폼 제출 테스트, 웹에서 실제 구매 등 브라우저 작업 자동화.
  • playwright show 명령: 헤드리스 실행 중에도 모든 브라우저 에이전트 동작을 시각적 대시보드로 표시. 영상에서 별도 언급한 숨겨진 팁.

8. GitHub CLI

코딩 → GitHub 푸시 → 배포까지 자연어로 한 번에.

  • Claude Code는 git/GitHub에 이미 능숙 → 별도 스킬 없이도 충분.
  • 원하면 Skill Creator로 커스텀 스킬 생성 가능.
  • 설치: GitHub CLI 공식 페이지에서 OS별 설명 참조. Claude Code에게 설치 요청 가능.
  • Vercel CLI와 함께 사용 시 시너지 극대화.

9. Firecrawl

AI 에이전트 맞춤 웹스크래핑 CLI + 스킬.

  • 설치 + 스킬 포함: 검색 → 한 줄 명령어로 CLI와 스킬 동시 설치.
  • 핵심 4개 명령: scrape (단일 페이지) / crawl (사이트 전체) / map (사이트 구조 파악) / search (검색 결과 스크래핑). Claude Code가 상황에 맞는 명령 자동 선택.
  • 사용 사례: 경쟁사 리서치, 문서 사이트 변경 모니터링, 소스 기반 심층 리서치.
  • Claude Code 내장 웹검색보다 "확실히 한 단계 위" — 화자 평가.

10. Excalidraw 다이어그램 스킬

자연어로 Excalidraw 다이어그램을 생성하는 스킬. 제작자: Cole Medin.

  • 설치: GitHub 레포 클론 → 프로젝트 스킬 디렉터리에 복사.
  • 최적 사용법: 다이어그램으로 만들 내용이 담긴 지식 디렉터리를 Claude Code에 포인팅 → "각 단계를 차트로 만들어줘"라고 요청.
  • 발표 자료 다이어그램을 Claude Code가 전부 생성 → 수작업 완전 제거.
  • Claude Code의 "6단계" 영상 다이어그램 전부 이 스킬로 제작했다고 화자가 밝힘.

전체 전사 펼치기

Claude Code를 사용하고 계신다면, 지금 플러그인과 애드온 생태계가 정말 폭발적으로 성장하고 있다는 걸 아실 겁니다. 새로운 MCP든, 새로운 CLI든, 새로운 스킬이든, 새로운 프레임워크든, 매일매일 새로운 것들이 쏟아져 나오고 있습니다. 쓸모 있는 것과 없는 것을 구분하는 게 불가능하게 느껴질 정도죠. 그래서 이 영상에서 제가 추천하는 Claude Code 플러그인 및 CLI 도구 탑 10을 보여드리겠습니다. 이것들은 제가 실제로 사용하고 있고, 진정한 가치를 제공한다고 믿는 도구들입니다.

각 도구에 대해 4가지를 알려드리겠습니다: 왜 관심을 가져야 하는지, 어떻게 사용하는지, 어떻게 설치하는지, 그리고 실제 사용 사례.

첫 번째 도구 — Supabase (CLI vs MCP)

Supabase MCP 서버에 왜 관심을 가져야 할까요? 두 가지 이유: 데이터베이스와 인증입니다. 개발하다 보면 언젠가는 이 둘이 필요한 프로젝트를 만들게 됩니다. Supabase는 이 두 가지를 모두 처리해 줄 수 있고, 매우 넉넉한 무료 티어를 제공합니다. 오픈소스 도구 위에 구축된 래퍼로, 셀프 호스팅과 로컬 개발도 가능합니다.

솔직하게 말씀드리겠습니다 — 사실 Supabase MCP 서버는 실제로 사용할 필요가 없습니다. 대신 Supabase CLI를 사용해야 합니다. 저 자신도 최근까지 MCP를 쓰고 있었습니다. 댓글에서 지적받기 전까지 CLI 버전이 존재한다는 걸 몰랐거든요. 이 분야를 매일 다루는 저도 그랬습니다. 얼마나 빠르게 변하는지 보여주는 사례죠.

CLI vs MCP 핵심 논점: MCP는 2024년 Anthropic이 만든 AI와 데이터 시스템 연결 표준입니다. 하지만 2026년 현재 Claude Code는 터미널 안에서 직접 실행됩니다. 그래서 CLI 도구가 MCP보다 더 적합합니다. MCP는 기본적으로 CLI 도구가 하는 걸 터미널 밖에서 흉내 내는 것 — 추가 오버헤드가 발생합니다. 따라서 CLI와 MCP 둘 다 있다면 항상 CLI를 선택하세요.

CLI 설치 시 주의: 새로운 CLI 도구를 추가할 때는 반드시 GitHub이나 공식 문서에서 대응 스킬이 있는지 확인하세요. Supabase는 Claude Code 플러그인 마켓플레이스에 공식 스킬이 있습니다.

두 번째 도구 — Skill Creator (Anthropic 공식)

오늘 10개 중 가장 강력한 도구라고 생각합니다. 며칠 전에 출시됐습니다. 단순히 스킬을 만들 수 있어서가 아니라, 기존 스킬을 수정·개선하고 성능을 측정할 수 있기 때문입니다. Anthropic이 블로그 전체를 할애해 설명했습니다.

이전에는 스킬이 실제로 더 나아지고 있는지 감에 의존하거나 모호한 상태였습니다. 이제는 데이터가 있습니다. 스킬을 적용했을 때와 안 했을 때 AB 테스트 가능. 현재 버전과 이전 버전 비교도 가능합니다.

설치: /plugin → Skill Creator 검색 → 설치. 사용: /skill-creator 또는 자연어로 "스킬 크리에이터를 사용해서 새 스킬 만들어줘". 내부는 Anthropic GitHub의 Claude Code 스킬 섹션에 공개된 텍스트 프롬프트입니다.

세 번째 도구 — GSD (Get Sh*t Done) 프레임워크

Claude Code 위에 올라가는 오케스트레이션 레이어로, 새 프로젝트를 시작할 때 Claude Code의 작동 방식을 바꿔줍니다. 스펙 기반 개발에 대한 가드레일을 제공합니다. 새 계획의 각 부분을 실행할 때마다 새로운 컨텍스트 윈도우와 서브에이전트를 사용 — 컨텍스트 윈도우 후반부에서 출력 품질이 저하되는 문제를 방지합니다.

GitHub에서 GSD 또는 Get Done 검색 → 한 줄 명령어로 설치. /gsd new project 입력 시 스팩 파악을 위한 상세 플래닝 모드가 시작됩니다.

네 번째 도구 — NotebookLM-PI

제 Claude Code 리서치 워크플로우의 핵심입니다. NotebookLM을 Claude Code 터미널에서 사용할 수 있게 해주는 CLI + 스킬입니다. 공식 API가 없는데도 리서치, 분석, 영상, 인포그래픽, 슬라이드덱, 플래시카드, 팟캐스트 같은 산출물 생성이 가능합니다. 거의 무료입니다.

설치: GitHub에서 명령어 복사 → 의존성 설치 → notebooklm 실행 → 브라우저 팝업 → 계정 로그인. CLI 도구이므로 스킬도 함께 설치해야 합니다. 반드시 스택에 추가하세요.

다섯 번째 도구 — Obsidian

Claude Code를 개인 비서로 쓰는 분께 완벽합니다. Obsidian은 텍스트 파일들이 어떻게 연결되는지 보여주고 체계적으로 관리해줍니다. 별도 CLI나 스킬이 불필요합니다. Obsidian을 다운로드하고 볼트로 지정할 폴더를 만든 뒤 그 폴더에서 Claude Code를 열기만 하면 됩니다. 화자의 폴더명은 말 그대로 "The Vault"입니다. 이후 "마크다운 파일 작성 시 Obsidian 규칙을 따르라"고 말하면 끝.

주의: 일반 코딩 프로젝트에는 큰 가치 없음. 대용량 마크다운 컨텍스트가 쌓이는 개인 비서 용도에 최적.

여섯 번째 도구 — Vercel CLI

배포 관리를 더 쉽게 해줍니다. 무료 티어가 훌륭합니다. 설치는 Claude Code에게 "Vercel CLI 설치해줘"라고 말하면 됩니다. Vercel 공식 웹사이트에 스킬 제공 중. 에이전트 루프와 함께 쓰면 특히 좋습니다 — 프로젝트 변경 시마다 자동 배포 상태 확인 루프 구성 가능.

일곱 번째 도구 — Playwright CLI

Claude Code의 브라우저 자동화 능력을 강화합니다. Microsoft 오픈소스로 매우 인기 있습니다. 설치: GitHub → 명령어 복사 → 의존성 설치 → playwright install skills.

UI 디자인 테스트, 폼 제출 테스트, 앱 변경 시 수동 테스트 자동화에 활용. 자연어로 지시하면 됩니다. 별도로 언급한 팁: playwright show 명령 — 헤드리스 실행 중에도 모든 브라우저 에이전트의 동작을 시각적 대시보드로 표시.

여덟 번째 도구 — GitHub CLI

코딩부터 GitHub 푸시, 배포까지 자연어로 한 곳에서 처리. Claude Code는 git/GitHub에 이미 능숙하므로 별도 스킬 없이도 충분히 활용 가능. 필요하면 Skill Creator로 커스텀 스킬 직접 생성.

아홉 번째 도구 — Firecrawl

AI 에이전트에 맞춤 제작된 웹스크래핑 CLI + 스킬. 설치 한 줄에 스킬도 포함됩니다. 핵심 명령 4가지: scrape / crawl / map / search. 이 4개가 다 같은 것처럼 보이지만, Claude Code가 상황에 맞는 명령을 자동 선택합니다 — 그래서 스킬이 필요한 이유입니다. 경쟁사 리서치, 문서 변경 모니터링, 심층 리서치에 활용. Claude Code 내장 웹검색보다 확실히 한 단계 위.

열 번째 도구 — Excalidraw 다이어그램 스킬

제가 개인적으로 가장 좋아하는 도구 중 하나입니다. 제작자는 Cole Medin — 이 분야의 대가 중 한 분. Claude Code에서 자연어로 다이어그램을 만들 수 있게 해줍니다. 화자의 "Claude Code 6단계" 영상의 다이어그램 전부가 이 스킬로 만들어진 것. 수작업 없이 시간을 엄청 절약했다고 밝혔습니다.

설치: GitHub 레포 클론 → 프로젝트 스킬 디렉터리에 복사. 최적 사용법: 다이어그램으로 만들 내용이 담긴 지식 디렉터리를 Claude Code에 포인팅 → "각 단계를 차트로 만들어줘". 발표나 프레젠테이션 자료 제작에 특히 강력합니다.

마무리

이 10가지 도구 중 최소 하나는 새롭게 알게 되셨기를 바랍니다. 주의할 점: 도구가 늘어난다고 성능도 같이 늘어나는 건 아닙니다. 너무 많이 추가하는 것도 함정입니다. 적절한 균형점을 찾는 것이 중요합니다.
