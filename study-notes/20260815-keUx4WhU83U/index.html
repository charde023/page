핵심 학습 포인트 (내가 배워야 할 것)

개념 왜 중요한가 한 줄
ChatGPT Work 일반 채팅과 달리 파일, 브라우저, 플러그인, 업무 도구를 연결해 실제 작업을 수행한다 질문보다 작업 위임에 가깝다
데스크톱 앱(Desktop App) 일부 기능은 웹 버전이 아니라 전용 데스크톱 앱에서만 동작한다 Work 모드는 데스크톱 앱 기준으로 봐야 한다
커스텀 스킬(Custom Skill) 회사 내부 도구나 API 없는 업무 흐름을 AI에게 가르칠 수 있다 반복 업무 매뉴얼을 AI용 절차로 만든다
플러그인(Plugin) 데이터 분석, 사이트 제작, 스프레드시트 등 특정 작업 능력을 추가한다 필요한 도구를 붙이면 결과물 품질이 올라간다
웹 자동화(Web Automation) API가 없는 웹 서비스도 브라우저 조작으로 처리할 수 있다 사람이 클릭하던 일을 AI가 대신한다
엑셀 모델 자동화 원본 데이터 통합, 수식 기반 모델, 그래프, 추천까지 만들 수 있다 단순 표가 아니라 검증 가능한 엑셀 파일을 만든다
리드 조사(Lead Research) 여러 지역·조건을 병렬 조사하고 검증 URL까지 정리한다 B2B 영업 전 조사 시간을 크게 줄인다
원격 실행(Remote) 컴퓨터에서 시작한 장기 작업을 휴대폰에서 확인·추가 지시할 수 있다 긴 작업을 맡겨놓고 이동 중에도 관리한다

내가 모를 만한 것 / 처음 보는 것

  • ChatGPT Work — OpenAI의 데스크톱 기반 업무용 AI 에이전트. 파일, 브라우저, 플러그인, 도구 연결을 통해 실제 결과물을 만든다.
  • Work 모드(Work Mode) — ChatGPT 앱 상단 토글에서 채팅(Chat)이 아니라 작업(Work)으로 바꾸는 모드.
  • 커스텀 스킬(Custom Skill) — 특정 회사의 업무 방식, 도구 접속법, 데이터 처리 방식을 ChatGPT Work에게 알려주는 사용자 정의 절차.
  • BigQuery — 구글 클라우드의 데이터 웨어하우스(Data Warehouse). 대량 데이터를 SQL로 분석할 때 쓴다.
  • 사이트 플러그인(Sites Plugin) — 대시보드나 웹 페이지 같은 공유 가능한 사이트를 만드는 기능.
  • 스프레드시트 플러그인(Spreadsheets Plugin) — 엑셀 파일 생성, 수식 작성, 템플릿 기반 모델링에 쓰는 기능.
  • 코호트 분석(Cohort Analysis) — 같은 시점에 유입된 사용자 그룹이 시간이 지나며 얼마나 유지되는지 보는 분석.
  • 서브 에이전트(Sub-agent) — 큰 작업을 지역, 주제, 검증 업무 등으로 나눠 동시에 처리하는 하위 에이전트.
  • Short.io — 추적용 짧은 링크를 만드는 서비스. 영상별 유입 추적에 사용됨.
  • 원격 기능(Remote Feature) — 데스크톱에서 실행 중인 ChatGPT Work 세션을 휴대폰에서 확인하고 이어서 지시하는 기능.

  17. 이미지 생성은 블로그 피처 이미지 9개 제안을 만들었고, 작업 시간은 약 12분이었다.

  19. 원격 기능은 데스크톱 컴퓨터가 켜져 있어야 작동한다 — 데스크톱 파일 접근 권한이 필요하기 때문이다.

2 대화형 대시보드 스크린샷과 데이터 연결을 이용해 공유 가능한 실시간 대시보드를 만든다
3 웹 자동화 에이전트 브라우저를 직접 조작해 이미지 다운로드, 파일 저장, CSV 생성을 자동화한다
4 Excel 모델 만들기 여러 원본 데이터를 합쳐 수식 기반 코호트 분석 엑셀 파일을 만든다

6 지출 관리 자동화 영수증 사진을 폴더에 넣으면 분류, 보관, 엑셀 기록까지 처리한다
7 여러 도구 데이터 일괄 수정 짧은 링크 생성과 유튜브 설명 수정처럼 도구를 넘나드는 작업을 맡긴다
8 이미지 생성 워크플로 기존 스타일을 학습해 블로그·광고·이메일용 이미지를 여러 개 생성한다
9 휴대폰 원격 실행 컴퓨터에서 시작한 장기 작업을 모바일에서 확인하고 추가 지시한다

1. ChatGPT Work는 답변 도구가 아니라 작업 실행 에이전트다

ChatGPT Work는 데스크톱에서 실행되는 AI 에이전트(AI Agent)다. 일반 ChatGPT처럼 답변만 주는 것이 아니라, 내가 작업 중인 파일을 보고, 자체 브라우저를 사용하고, 매일 쓰는 업무 도구 안에서 실제 행동을 수행할 수 있다.

핵심은 “무엇을 해야 하는지 알려주면, 결과물을 만들 때까지 진행한다”는 점이다. 영상에서는 이를 대시보드 제작, 웹 데이터 수집, 엑셀 모델링, 리드 조사, 영수증 정리, 유튜브 설명 수정, 이미지 생성, 휴대폰 원격 실행으로 보여준다.

사용 전제는 명확하다. 웹 버전이 아니라 전용 ChatGPT 데스크톱 앱을 사용해야 한다. 앱에서 왼쪽 상단이 ChatGPT로 선택되어 있는지 확인하고, 상단 토글을 Chat에서 Work로 바꾸면 ChatGPT Work 모드가 된다.

2. 사용 사례 1: 대화형 유튜브 대시보드 만들기

첫 번째 사례는 유튜브 성과를 확인하는 대화형 대시보드(Interactive Dashboard) 제작이다.

화자는 먼저 구글에서 “YouTube analytics dashboard”를 검색해 마음에 드는 대시보드 이미지를 찾았다. 그 이미지를 복사해 ChatGPT Work에 붙여넣고, “첨부한 스크린샷처럼 유튜브 대시보드를 라이브 사이트로 재현해 팀과 공유할 수 있게 해달라”고 요청했다.

여기서 연결한 요소는 세 가지다.

  • YouTube 채널 커스텀 스킬(Custom Skill)
  • 데이터 분석 플러그인(Data Analytics Plugin)
  • 사이트 플러그인(Sites Plugin)

YouTube 채널 커스텀 스킬은 ChatGPT Work가 유튜브 채널 데이터에 접근하는 방법을 알려준다. 데이터 분석 플러그인은 BigQuery 같은 데이터 웨어하우스(Data Warehouse)에 연결해 쿼리하는 역할을 한다. 사이트 플러그인은 공유 가능한 웹 대시보드를 만드는 데 쓰인다.

결과물은 유튜브 채널 로고, 최근 30일 핵심 지표, 일별 조회수, 평균 시청 지속 시간, 총 시청 시간, 요일별 성과, 최신 영상 표까지 포함한 대시보드였다.

중요한 점은 첫 결과물이 완벽하지 않았다는 것이다. 처음에는 차트에 마우스를 올렸을 때 구체 숫자가 보이지 않았다. 화자는 “차트에 호버하면 해당 날짜나 세그먼트의 숫자를 보여줄 수 있냐”고 피드백했고, ChatGPT Work는 약 4분 동안 수정해 대화형 기능을 추가했다.

기존 방식이라면 BI팀이나 데이터 분석팀에 요청하고 2~3주를 기다릴 수 있는 작업이지만, 여기서는 몇 분 만에 초안을 만들고 다시 몇 분 만에 수정했다는 점이 핵심이다.

3. 사용 사례 2: 웹 자동화 에이전트로 이미지 수집하기

두 번째 사례는 ChatGPT Work의 자체 브라우저를 이용한 웹 자동화(Web Automation)다.

화자는 9x 블로그의 피처 이미지들이 일정한 스타일을 갖고 있으므로, 나중에 비슷한 이미지를 생성하기 위해 기존 이미지들을 수집하고 싶어 했다. 사람이 직접 글마다 우클릭해서 저장하는 대신, ChatGPT Work에게 블로그 페이지 링크를 주고 다음 작업을 맡겼다.

  • 블로그 목록 페이지 방문
  • 첫 20개 글의 피처 이미지 다운로드
  • 이미지를 폴더에 저장
  • 글 제목과 이미지 파일명을 연결한 CSV 생성

ChatGPT Work는 브라우저를 열고 페이지를 확인한 뒤, 필요한 이미지를 내려받았다. 사람처럼 우클릭 저장을 할 수도 있지만, 상황에 따라 간단한 자바스크립트(JavaScript)를 작성해 빠르게 다운로드할 수 있다.

이 방식은 특히 API가 없는 도구에서 유용하다. 예를 들어 어떤 플랫폼이 커넥터(Connector)나 MCP 서버(MCP Server)를 제공하지 않아도, ChatGPT Work가 웹사이트에 로그인하고 월별 인보이스를 내려받아 지정 폴더에 넣는 식의 자동화를 할 수 있다.

4. 사용 사례 3: 복잡한 Excel 코호트 분석 모델 만들기

세 번째 사례는 엑셀 모델 자동화다. 화자는 수작업으로 하기 부담스러운 코호트 분석(Cohort Analysis)을 ChatGPT Work에 맡겼다.

입력 데이터는 다섯 가지였다.

  • Circle 커뮤니티 회원 데이터
  • 회원 활동 로그
  • 라이브 이벤트 플랫폼 데이터
  • Stripe 결제 거래 데이터
  • 이전 커뮤니티 도구에서 내보낸 데이터

요청은 “이 다섯 개의 export 파일을 이용해 하나의 Excel workbook으로 제대로 된 코호트 분석을 만들어 달라”는 것이었다.

여기서 핵심 조건은 하드코딩된 숫자를 쓰지 말고 모든 계산을 엑셀 수식(Formula)으로 만들라는 지시였다. 숫자를 그냥 붙여 넣으면 정확한지 검증하기 어렵다. 반대로 수식으로 만들면 사용자가 셀을 클릭해 계산 방식과 참조 범위를 확인할 수 있다.

ChatGPT Work는 스프레드시트 플러그인(Spreadsheets Plugin)을 사용해 1시간 7분 44초 동안 작업했다. 약 35MB 규모의 데이터, 수천 행을 처리했고, 최종 엑셀 파일에는 원본 데이터 탭, 사람 정보, 활성 월, 리텐션 탭, 소스별 코호트 분석, 그래프, 추천 사항까지 들어갔다.

또 하나 중요한 기능은 템플릿(Template)이다. 회사에 이미 쓰고 있는 엑셀 양식이 있다면, ChatGPT Work가 처음부터 모델을 창작하게 하지 않고 기존 템플릿에 원본 숫자만 넣고 반복 작업을 처리하게 만들 수 있다.

5. 사용 사례 4: 리드 조사 에이전트 만들기

네 번째 사례는 B2B 리드 조사(Lead Research)다. 화자는 9x가 제공하는 AI 교육 서비스에 관심 있을 만한 회사를 찾기 위해 커스텀 리드 조사 스킬을 만들었다.

검색 조건은 다음과 같았다.

  • 지역: 유럽 시장
  • 신호: AI 자동화 또는 운영 혁신 관련 채용 중
  • 신호: 최근 AI 이니셔티브 발표
  • 규모: 직원 50~500명
  • 산업: 운영 인력이 많은 업종
  • 목표 수량: 데모 기준 25개 회사

또한 기존 고객사와 과거 거래 회사를 제외하기 위해, 프로젝트 폴더 안에 이미 협업한 회사 목록도 넣어두었다.

화자는 모델 노력 수준(Effort)을 High에서 Ultra로 올렸다. 사용량은 더 들지만, 조사 품질과 복잡한 탐색에는 유리하기 때문이다.

작업 결과 ChatGPT Work는 20분 넘게 실행되며 여러 서브 에이전트(Sub-agent)를 만들었다. 예를 들어 베를린·함부르크, 뮌헨·빈·취리히, 영국·아일랜드처럼 지역별로 나누어 동시에 조사했다. 별도 서브 에이전트는 기존 고객사 제외 여부도 검증했다.

결과 엑셀에는 회사명, 구매 신호, 근거 URL, 잠재 의사결정자 이름, 직함, LinkedIn 프로필, 9x와의 적합성 요약, 신뢰도 점수가 포함됐다.

여기서 중요한 점은 AI가 단순히 “그럴듯한 회사”를 나열하는 것이 아니라, 검증 가능한 URL을 함께 제공한다는 것이다. B2B 영업에서는 허위 정보가 치명적이므로, 출처 확인이 필수다.

6. 사용 사례 5: 영수증과 지출 관리 자동화

다섯 번째 사례는 지출 관리다.

화자는 컴퓨터에 receipts라는 전용 폴더를 만들었다. 영수증을 추적하고 싶을 때 사진을 찍어 이 폴더에 넣으면 된다. 개인 지출 관리에도 쓸 수 있고, 사업 비용을 회계사에게 전달하기 전 정리하는 용도로도 쓸 수 있다.

ChatGPT Work에는 영수증 처리 전용 스킬을 만들어두었다. 평소에는 일정에 따라 자동 실행되지만, 데모에서는 수동으로 한 번 실행했다.

처리 흐름은 다음과 같다.

  1. receipts 폴더에서 새 영수증 이미지 확인
  2. 이미지에서 날짜, 금액, 상호, 카테고리 등 핵심 필드 추출
  3. 처리 완료된 영수증을 processed 폴더로 이동
  4. 영수증 날짜 기준으로 정리
  5. 엑셀 지출 기록 파일에 새 행 추가

사용자는 영수증 사진만 넣으면 되고, 나머지는 AI가 정리한다.

7. 사용 사례 6: 여러 도구의 데이터를 일괄 수정하기

여섯 번째 사례는 유튜브 설명란을 대량 수정하는 작업이다.

9x는 유튜브 설명란 링크를 통해 웹사이트 트래픽을 많이 얻는다. 특히 무료 리소스 링크나 AI 교육 문의 링크가 중요하다. 그런데 영상이 130개 이상이면, 모든 설명란에 새 콜투액션(Call to Action)을 추가하는 작업은 매우 번거롭다.

게다가 각 영상에는 추적 파라미터가 붙은 전용 짧은 링크(Short Link)가 필요하다. 즉, 단순히 같은 문장을 복붙하는 것이 아니라 영상별 ID를 넣어 Short.io에서 별도 링크를 만들고, 유튜브 설명란의 기존 구조를 이해해 적절한 위치에 삽입해야 한다.

화자는 먼저 ChatGPT Work에게 공개 영상 목록을 가져오게 했다. 각 영상의 ID, 제목, 게시일, 조회수, 설명란을 CSV와 마크다운 파일로 저장했다. 이 백업 단계가 중요한 이유는 두 가지다.

  • 기존 설명 구조를 ChatGPT Work가 이해할 수 있다.
  • 실제 설명란 수정 중 문제가 생기면 원본으로 되돌릴 수 있다.

그다음 프롬프트에서는 조건을 상세히 지정했다.

  • 설명이 리드 마그넷(Lead Magnet) 링크로 시작하면 그 아래에 교육 문의 CTA를 넣는다.
  • 설명 상단에 CTA가 없으면 첫 줄에 넣는다.
  • 구독 요청 CTA로 시작하면 그것을 교육 문의 CTA로 교체한다.
  • Short.io에서 영상 ID가 포함된 추적용 짧은 링크를 동적으로 만든다.

먼저 올해 게시된 약 20~30개 영상만 대상으로 테스트했다. 결과적으로 ChatGPT Work는 각 영상별 짧은 링크를 만들고, 유튜브 설명란을 수정하고, 무엇을 바꿨는지 목록으로 보여줬다.

이 사례의 핵심은 단순 반복이 아니라 문맥에 따른 조건부 수정이다. 설명란마다 구조가 다르기 때문에, 일반 자동화 도구보다 AI 에이전트가 잘 맞는 작업이다.

8. 사용 사례 7: 이미지 생성 워크플로에 ChatGPT Work 사용하기

일곱 번째 사례는 이미지 생성이다.

화자는 이미 앞에서 블로그 피처 이미지 20개를 다운로드해두었다. 이제 ChatGPT Work에게 기존 이미지 스타일을 분석하게 한 뒤, 새 블로그 글 3개에 대한 피처 이미지 후보를 만들게 했다.

요청한 글 제목은 다음과 같다.

  • ChatGPT Work versus Claude Code
  • What is ChatGPT Work and how to set it up
  • Seven browser automations every marketer should run in ChatGPT Work

화자는 각 글마다 3개씩 제안하라고 요청했다. 이미지 생성은 한 번에 마음에 드는 결과가 나오지 않을 수 있으므로, 여러 후보를 만들어 고를 수 있게 한 것이다.

ChatGPT Work는 약 12분 동안 작업해 총 9개 이미지를 만들었다. 기존 블로그 이미지의 해상도와 스타일을 맞췄고, 생성에 사용한 프롬프트도 마크다운 파일로 저장했다. 따라서 결과가 마음에 들지 않으면 어떤 지시 때문에 그런 이미지가 나왔는지 확인하고 수정할 수 있다.

이 방식은 블로그뿐 아니라 메타 광고(Meta Ads), 이메일 이미지, 캠페인 크리에이티브 등에도 적용할 수 있다.

9. 사용 사례 8: 휴대폰에서 장기 작업 이어가기

마지막 사례는 원격 실행(Remote) 기능이다.

ChatGPT Work 작업은 일반 채팅보다 오래 걸린다. 어떤 작업은 10분, 20분, 1시간 이상 실행된다. 그래서 컴퓨터에서 작업을 시작한 뒤, 이동 중 휴대폰에서 확인하고 추가 지시할 수 있는 기능이 중요하다.

휴대폰 ChatGPT 앱에서 왼쪽 메뉴의 Remote 섹션으로 들어가면, 컴퓨터에서 시작한 ChatGPT Work 세션을 볼 수 있다. 영상에서는 Face ID 인증 후, 유튜브 설명란 수정 작업이 완료된 것을 확인하고 “이제 2025년 모든 영상에도 실행해달라”고 휴대폰에서 추가 지시했다.

중요한 제약도 있다. 데스크톱 버전이 컴퓨터 파일과 도구에 접근하는 구조이므로, 해당 컴퓨터가 켜져 있어야 한다.

종합 체크리스트

  • [ ] ChatGPT 데스크톱 앱을 설치하고 Work 모드 위치를 확인한다.
  • [ ] 내가 매주 반복하는 업무 3개를 적어본다.
  • [ ] 각 업무에 필요한 파일, 웹사이트, 로그인 도구, 엑셀 양식을 정리한다.
  • [ ] 자주 쓰는 업무 절차를 커스텀 스킬(Custom Skill) 후보로 만든다.
  • [ ] 대시보드 작업은 스크린샷 레퍼런스와 데이터 소스를 함께 제공한다.
  • [ ] 엑셀 자동화 요청 시 “하드코딩 금지, 수식으로 작성”을 명시한다.
  • [ ] 웹 자동화 전에는 원본 데이터를 백업하게 한다.
  • [ ] 리드 조사 결과에는 반드시 근거 URL과 신뢰도 점수를 요구한다.
  • [ ] 도구 일괄 수정은 먼저 작은 범위로 테스트한다.
  • [ ] 장기 작업은 컴퓨터에서 시작하고 휴대폰 Remote로 상태를 확인한다.

이 영상에서는 OpenAI의 새로운 ChatGPT Work를 활용하는 8가지 대표 사용 사례를 소개한다. ChatGPT Work는 데스크톱에서 실행되는 AI 에이전트(AI Agent)로, 사용자가 작업 중인 파일을 볼 수 있고, 자체 브라우저를 사용하며, 매일 쓰는 업무 도구 안에서 실제 행동을 수행할 수 있다. 즉, 단순히 답을 주는 것이 아니라 실제 작업을 처리한다.

먼저 ChatGPT 데스크톱 앱을 열어야 한다. 중요한 점은 웹 버전이 아니라 전용 데스크톱 앱을 써야 한다는 것이다. 일부 사용 사례는 데스크톱 앱에서만 가능하다. 앱 왼쪽 상단에서 Codex가 아니라 ChatGPT가 선택되어 있는지 확인하고, 상단 토글을 Chat에서 Work로 바꾸면 ChatGPT Work 모드가 된다.

첫 번째 사용 사례는 대화형 대시보드(Interactive Dashboard) 제작이다. 화자는 유튜브 영상 성과를 팀과 함께 확인하기 위한 대시보드를 만들고 싶어 했다. 먼저 구글에서 유튜브 분석 대시보드 이미지를 검색해 마음에 드는 예시를 찾고, 그 이미지를 ChatGPT Work에 붙여넣었다. 그런 다음 “첨부한 스크린샷처럼 유튜브 대시보드를 라이브 사이트로 재현하고, 유튜브 채널과 BigQuery의 실시간 데이터를 가져오라”고 요청했다.

이때 YouTube 채널에 연결하는 커스텀 스킬(Custom Skill), 데이터 웨어하우스에 연결하는 데이터 분석 플러그인(Data Analytics Plugin), 대시보드를 웹사이트로 만드는 사이트 플러그인(Sites Plugin)을 함께 사용했다. 결과물은 유튜브 채널 로고, 최근 30일 핵심 지표, 일별 조회수, 평균 시청 지속 시간, 총 시청 시간, 요일별 성과, 최신 영상 표를 포함한 실시간 대시보드였다.

다만 첫 결과가 완벽했던 것은 아니다. 처음에는 차트에 마우스를 올렸을 때 숫자가 표시되지 않았다. 화자는 “차트에 호버하면 특정 날짜나 세그먼트의 숫자가 나오게 해달라”고 피드백했고, ChatGPT Work는 약 4분 동안 수정해 이를 반영했다. 기존 BI팀이나 데이터 분석팀에 요청하면 2~3주 걸릴 수 있는 작업이 몇 분 만에 초안으로 나오고, 수정도 빠르게 가능하다는 점이 강조된다.

두 번째 사용 사례는 웹 자동화(Web Automation)다. ChatGPT Work 데스크톱 앱에는 자체 브라우저가 있으며, 사이드 패널에서 열 수 있다. 화자는 9x 블로그의 피처 이미지들이 일정한 스타일을 갖고 있으므로, 나중에 비슷한 이미지를 만들기 위해 기존 이미지를 모으고 싶어 했다. 직접 우클릭해 저장하는 대신, 블로그 목록 링크를 ChatGPT Work에 주고 첫 20개 글의 피처 이미지를 다운로드하고, 각 글 제목과 이미지 파일을 연결한 CSV를 만들라고 요청했다.

ChatGPT Work는 브라우저로 블로그를 방문하고, 이미지를 다운로드해 폴더에 저장했으며, CSV 파일도 만들었다. 이런 자동화는 API나 전용 커넥터가 없는 도구에서 특히 유용하다. 예를 들어 매달 특정 플랫폼에 로그인해 인보이스를 다운로드하고 지정 폴더에 넣는 작업도 맡길 수 있다.

세 번째 사용 사례는 엑셀 모델 작성이다. 화자는 수작업으로 하기 복잡한 코호트 분석(Cohort Analysis)을 맡겼다. 입력 데이터는 Circle 커뮤니티 회원 정보, 활동 로그, 라이브 이벤트 플랫폼 데이터, Stripe 결제 데이터, 이전 커뮤니티 도구 데이터 등 다섯 가지였다. 요청은 이 데이터를 하나의 Excel workbook으로 합쳐 제대로 된 코호트 분석을 만들라는 것이었다.

중요한 지시는 모든 계산을 수식(Formula)으로 만들고, 하드코딩된 숫자는 넣지 말라는 것이었다. 그래야 사용자가 계산 과정을 추적하고 오류 여부를 확인할 수 있다. ChatGPT Work는 스프레드시트 플러그인(Spreadsheets Plugin)을 사용해 1시간 7분 44초 동안 작업했고, 약 35MB 규모의 데이터를 처리했다. 최종 파일에는 원본 데이터 탭, 사람 정보, 활성 월, 리텐션 분석, 소스별 코호트 분석, 그래프, 추천 사항이 들어 있었다. 그래프도 이미지가 아니라 엑셀 모델의 데이터를 참조해 편집 가능한 형태였다.

또한 스프레드시트 플러그인은 템플릿(Template)을 사용할 수 있다. 회사에 이미 쓰는 엑셀 모델이 있다면, ChatGPT Work가 모델을 처음부터 새로 만들게 하지 않고, 기존 템플릿에 원본 데이터를 넣고 반복 작업만 처리하게 할 수 있다.

네 번째 사용 사례는 리드 생성 및 리드 조사(Lead Research)다. 화자는 9x의 AI 교육 서비스에 관심 있을 만한 회사를 찾기 위해 리드 조사 스킬을 만들었다. 조건은 유럽 시장, AI 자동화 또는 운영 혁신 역할을 채용 중인 회사, 최근 AI 이니셔티브를 발표한 회사, 직원 50~500명 규모, 운영 인력이 많은 업종이었다. 데모에서는 25개 회사를 찾게 했다.

프로젝트 폴더에는 이미 협업했거나 현재 고객인 회사 목록도 넣어두어, 검색 결과에서 제외하게 했다. 화자는 모델의 노력 수준(Effort)을 High에서 Ultra로 올렸다. 사용량은 더 들지만, 복잡한 조사에는 더 적합하기 때문이다.

작업은 20분 넘게 걸렸고, ChatGPT Work는 여러 서브 에이전트(Sub-agent)를 만들었다. 예를 들어 베를린·함부르크, 뮌헨·빈·취리히, 영국·아일랜드처럼 지역별로 나눠 동시에 조사했다. 또 다른 서브 에이전트는 기존 고객사가 제외되었는지 확인했다. 결과에는 회사명, 구매 신호, 근거 URL, 잠재 의사결정자 이름과 직함, LinkedIn 프로필, 9x와의 적합성 요약, 신뢰도 점수가 포함됐다. 특히 각 신호마다 확인 가능한 URL을 제공해 검증할 수 있었다.

다섯 번째 사용 사례는 지출 관리다. 화자는 컴퓨터에 receipts라는 폴더를 만들었다. 영수증을 추적하고 싶을 때 사진을 찍어 이 폴더에 넣으면 된다. ChatGPT Work에는 영수증 처리 전용 스킬을 만들어두었고, 새 영수증이 들어오면 이미지를 읽어 날짜, 금액, 상호, 카테고리 같은 정보를 추출한다. 이후 영수증 파일을 processed 폴더로 옮기고 날짜 기준으로 정리하며, 엑셀 지출 기록 파일에 새 행을 추가한다.

여섯 번째 사용 사례는 여러 도구에 걸친 데이터 일괄 수정이다. 9x는 유튜브 설명란 링크를 통해 웹사이트 트래픽을 얻는다. 특히 AI 교육에 관심 있는 회사가 쉽게 문의할 수 있도록 새 링크를 여러 영상 설명에 추가하고 싶어 했다. 하지만 채널에는 130개가 넘는 영상이 있고, 각 영상마다 추적 파라미터가 들어간 전용 짧은 링크(Short Link)를 만들어야 했다. 또한 설명란 구조가 영상마다 달라 단순 복사 붙여넣기로는 어렵다.

화자는 먼저 ChatGPT Work에게 공개 영상 목록을 가져오고, 각 영상의 ID, 제목, 게시일, 조회수, 설명란을 CSV와 마크다운 파일로 저장하게 했다. 이렇게 하면 기존 설명 구조를 이해할 수 있고, 문제가 생겼을 때 원본으로 되돌릴 수 있다. 이후 Short.io에 연결하는 스킬을 사용해 영상 ID가 포함된 추적 링크를 만들고, 설명란 구조에 따라 새 콜투액션(Call to Action)을 적절한 위치에 넣게 했다. 리드 마그넷 링크가 있으면 그 아래에 넣고, CTA가 없으면 첫 줄에 넣고, 구독 요청 CTA가 있으면 이를 대체하게 했다. 먼저 올해 게시된 20~30개 영상만 대상으로 테스트했고, 결과적으로 각 영상별 짧은 링크와 설명란 수정이 완료됐다.

일곱 번째 사용 사례는 이미지 생성 워크플로다. 앞서 다운로드한 블로그 피처 이미지 20개를 바탕으로, ChatGPT Work에게 기존 이미지의 형식, 스타일, 해상도를 분석하게 했다. 그런 다음 새 블로그 글 3개에 대해 각각 3개씩, 총 9개의 피처 이미지 후보를 만들게 했다. 이미지 생성은 약 12분 걸렸고, 결과물은 기존 블로그 스타일과 비슷한 형식으로 저장됐다. 또한 실제 생성에 사용한 프롬프트를 마크다운 파일로 함께 저장해, 마음에 들지 않는 결과가 있다면 어떤 지시 때문에 그렇게 나왔는지 확인하고 개선할 수 있었다.

이 방식은 블로그 이미지뿐 아니라 메타 광고(Meta Ads) 변형, 이메일용 이미지, 기타 마케팅 크리에이티브에도 적용할 수 있다. 기존에 AI 이미지 생성으로 좋은 결과를 얻은 스타일이 있다면, 이를 업무 흐름 안에 넣어 자동으로 여러 후보를 만들 수 있다.

여덟 번째 사용 사례는 원격 기능(Remote Feature)이다. ChatGPT Work 작업은 일반 채팅보다 오래 걸릴 수 있다. 어떤 작업은 10분, 20분, 1시간 이상 실행된다. 그래서 컴퓨터에서 작업을 시작한 뒤 휴대폰에서 상태를 확인하고 추가 지시를 내릴 수 있는 기능이 유용하다.

휴대폰 ChatGPT 앱의 왼쪽 메뉴에서 Remote로 들어가면, 컴퓨터에서 시작한 ChatGPT Work 세션을 볼 수 있다. 영상에서는 Face ID 인증 후, 유튜브 설명란 수정 작업이 완료된 것을 확인하고 “이제 2025년 모든 영상에도 실행해달라”고 휴대폰에서 추가 지시했다. 이때 노트북 화면에서도 해당 작업이 시작되는 것을 볼 수 있었다.

단, 데스크톱 버전이 컴퓨터 파일과 도구에 접근하는 구조이므로, 해당 컴퓨터가 켜져 있어야 한다. 이 조건만 충족되면 어디서든 장기 작업을 확인하고 이어갈 수 있다.

결론적으로 화자는 ChatGPT를 단순히 질문하는 곳으로 쓰지 말고, 실제 업무를 처리하게 하는 도구로 써야 한다고 말한다. 브라우징, 업무 도구 접근, 최종 결과물 생성을 맡기고, 한 주 동안 가장 자주 반복하는 일을 찾아 먼저 넘기면 다음 주부터 시간을 절약할 수 있다.
