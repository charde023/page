1. 제품 발표 — Gemini 3.5 Live Translate API 공개

Google이 Gemini 3.5 Live Translate를 개발자 API로 공개했다. 이 모델은 음성-음성(speech-to-speech) 실시간 번역에 특화돼 있으며, 이미 Google 번역 앱 내부에서 동작하고 있던 모델을 외부 API로 개방한 것이다.

지원 언어는 입력·출력 모두 70개 이상, 오늘부터 바로 통합 가능하다.

2. 데모 1 — 라이브 더빙 (탭 오디오 번역)

브라우저 탭의 오디오 스트림을 API로 흘려보내 실시간으로 다른 언어 음성으로 출력하는 시나리오. 데모에서는 Google I/O 키노트 영상을 힌디어로 실시간 더빙했다.

이 방식으로 활용 가능한 시나리오: - 외국어 웨비나·유튜브를 모국어 음성으로 실시간 청취 - OTT 컨텐츠 실시간 더빙 프로토타이핑 - 기업 내 다국어 방송 시스템

3. 데모 2 — 발표 세션 다국어 동시 청취

발표자가 한 명이더라도 다국어 청중을 동시에 서비스할 수 있는 세션 구조다:

  1. 발표자가 세션 생성 → URL 또는 QR 코드 획득
  2. 청중이 QR 스캔 후 원하는 언어 선택
  3. 각 언어마다 독립적인 Live API 세션이 백엔드에서 생성됨
  4. 발표자가 언어를 전환해도 자동 감지 — 별도 설정 불필요

데모에서 실시한 언어 전환 순서: 영어 → 일본어 → 스페인어 → 독일어 → 신할라어 → 일본어로 복귀. 모든 전환이 자동으로 인식됐다.

번역 품질: 끊김 없는 자연스러운 흐름 — 인위적인 멈춤이나 어색함 없이 원어처럼 들린다고 화자가 강조.
