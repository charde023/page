내가 모를 만한 것 / 처음 보는 것

  • 컴퓨터 사용(computer use) — AI가 브라우저나 앱을 직접 조작해 작업을 수행하는 능력.
  • 오케스트레이션(orchestration) — 하나의 상위 AI가 여러 하위 에이전트(agent)를 배치하고 조율하는 구조.
  • 악마의 대변인(devil’s advocate) — 일부러 반대 입장에서 문제점과 취약점을 찾아보는 검토 방식.
  • 공동창업자형 AI(co-founder AI) — 단순 비서가 아니라 전략, 판단, 피드백까지 함께하는 AI를 비유적으로 부르는 표현.
  • 컨설턴트형 응답(consultant-like response) — 사용자의 요청을 그대로 수행하기보다, 더 나은 방향을 위해 반론이나 대안을 제시하는 응답 방식.

  1. Fable은 “매니저(manager)” 또는 “공동창업자(co-founder)”에 가깝다 — 단순 수행자가 아니라 방향을 잡고 조율하는 역할로 평가했다.
  2. Sol은 “정말 좋은 작업자(worker)”에 가깝다 — 반복적으로 “really good worker”라고 강조하며 실행력 중심으로 설명했다.
  3. Fable이 여러 Sol 에이전트(agent)를 지휘하면 좋을 것 — 한 모델이 모든 일을 하기보다, 매니저와 실행자를 나누는 구조를 제안했다.
  4. Sol의 강점은 가격(price), 컴퓨터 사용(computer use), 악마의 대변인(devil’s advocate), 검증(verification) — 비용 효율과 실제 작업 실행, 꼼꼼한 검토에 더 강하다고 봤다.
  5. Fable은 때때로 더 강하게 반론을 제시한다 — 사용자의 요청을 바로 실행하기보다 “컨설턴트처럼” 되묻거나 방향을 수정하려는 성향이 있다고 설명했다.
  6. Fable의 반론 성향은 장점이자 단점 — 관리자로서는 좋은 특성이지만, 빠른 실행이 필요한 상황에서는 불편할 수 있다.

1. 전체 평가: Fable은 매니저, Sol은 작업자

화자는 Fable 5를 매니저(manager) 또는 공동창업자(co-founder) 같은 모델로 느낀다고 말한다. 즉, 사용자가 요청한 일을 단순히 수행하는 도구라기보다, 방향을 잡고 판단하며 조율하는 파트너에 가깝다는 뜻이다.

반면 GPT 5.6 Sol은 아주 뛰어난 작업자(worker)에 가깝다고 평가한다. Sol은 주어진 지시를 빠르고 정확하게 처리하는 쪽에 강점이 있다는 의미다.

이 구분은 AI 모델을 고를 때 중요하다.
예를 들어 이커머스나 물류 업무에서도 다음처럼 나눠볼 수 있다.

  • 전략, 기획, 우선순위 판단: Fable형 모델
  • 상품 등록, 데이터 정리, 반복 검증, 자동화 실행: Sol형 모델

2. 가장 좋은 구조: Fable이 Sol 에이전트들을 지휘

화자는 Fable이 여러 개의 Sol 에이전트(agent)를 오케스트레이션(orchestration)하면 매우 좋을 것이라고 말한다.

여기서 핵심은 한 모델이 모든 일을 혼자 하는 것이 아니라, 역할을 나누는 것이다.

  • Fable: 전체 목표 설정, 작업 분배, 결과 판단
  • Sol: 개별 작업 실행, 컴퓨터 조작, 검증, 오류 찾기

즉, Fable은 팀장처럼 일하고 Sol은 실무자처럼 움직이는 구조다. AI 에이전트 시대에는 이런 식의 역할 분리가 중요해질 수 있다.

3. Sol의 강점: 가격, 컴퓨터 사용, 검증

화자는 Sol이 Fable보다 나은 지점을 몇 가지로 정리한다.

첫째, 가격(price)이다. Sol이 비용 측면에서 더 유리하다고 본다. 실무에서 AI를 자주 쓰는 사람에게 가격은 매우 중요하다. 특히 반복 업무, 대량 처리, 자동화 작업에서는 모델 성능만큼 비용 효율도 중요하다.

둘째, 컴퓨터 사용(computer use)이다. Sol은 컴퓨터를 직접 다루거나 작업을 실행하는 능력에서 더 낫다고 평가된다. 이는 브라우저 조작, 파일 처리, 폼 입력, 시스템 내 작업 자동화 같은 영역과 연결된다.

셋째, 검증(verification)이다. Sol은 사용자가 무엇을 지시했는지, 자신이 무엇을 해야 하는지, 그 지시를 정확히 따르고 있는지 더 신중하게 확인하는 느낌이라고 설명한다.

4. Sol의 또 다른 강점: 악마의 대변인 역할

Sol은 악마의 대변인(devil’s advocate) 역할도 잘한다고 평가된다.

악마의 대변인이란 일부러 반대 입장에서 생각해보며 다음을 찾는 방식이다.

  • 논리의 허점
  • 숨어 있는 버그
  • 놓친 리스크
  • 다른 관점에서의 문제점

화자는 Sol이 “조금 더 조심스럽게” 버그를 찾고, 여러 각도에서 사안을 검토하는 느낌이라고 말한다. 그래서 결과물의 검증이나 오류 탐지에는 Sol이 유리할 수 있다.

5. Fable의 성향: 요청을 그대로 하기보다 반론하는 컨설턴트

Fable은 사용자의 요청을 그대로 실행하기보다, 때로는 반론하거나 방향을 제안하는 성향이 있다고 설명된다.

화자는 Fable이 약간 더 “건방진 듯한(sassier)” 느낌을 줄 때가 있다고 표현한다. 여기서 말하는 건 단순히 무례하다는 뜻이 아니라, 사용자의 요청을 곧바로 수행하기보다는 다음처럼 반응할 수 있다는 의미다.

  • “이 방식보다 다른 방식이 낫습니다.”
  • “그 요청은 다시 생각해봐야 합니다.”
  • “이 문제는 이렇게 접근하는 게 더 좋습니다.”

즉 Fable은 단순 실행자가 아니라 컨설턴트(consultant)처럼 행동한다.

6. 장단점: 매니저형 AI와 작업자형 AI는 쓰임이 다르다

Fable의 반론 성향은 장점이자 단점이다.

전략적 판단이 필요한 상황에서는 Fable의 반론이 도움이 된다. 사용자가 놓친 부분을 짚어주고, 더 나은 방향을 제시할 수 있기 때문이다.

하지만 빠르게 실행해야 하는 상황에서는 이런 반론이 오히려 방해가 될 수 있다. 사용자가 이미 할 일을 정했고, 단순히 실행만 원하는 경우에는 Sol처럼 지시를 정확히 따르는 모델이 더 편할 수 있다.

따라서 핵심은 “어느 모델이 무조건 더 좋다”가 아니라, 업무 유형에 따라 다르게 써야 한다는 점이다.

이것은 좋은 점이기도 합니다. 그래서 제가 Fable을 매니저라고 말한 것입니다. 다만 이런 특성에는 장단점이 모두 있습니다.
