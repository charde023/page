  • Uplift: AI가 악의적 행위자의 공격 능력을 "끌어올리는" 위험. Anthropic이 가드레일 근거로 제시.
  • Slay the Spire: 덱빌딩 로그라이크 게임. 장기 자율 작업 벤치마크로 사용됨 — Fable 5가 파일 기반 영구 메모리로 Opus 4.8보다 3배 향상된 성능을 보임.
  • Glasswing: Anthropic이 소수의 사이버 방어자·인프라 제공자에게 가드레일 없는 Mythos를 제공했던 프로그램.

  10. 30일 데이터 보존: 모델 학습이나 비안전 목적 사용 없음을 주장하나, 인간 접근 로깅 및 30일 후 삭제 정책 적용.
  11. 사이버보안·생물학·화학·distillation 4개 도메인이 가드레일 적용 대상.

1. 모델 구조와 배포 방식

Anthropic은 Mythos급 이라는 새로운 모델 티어를 도입했다. 기존 Sonnet, Opus 위에 위치한다. 일반 사용자가 받는 것은 Claude Fable 5 — Mythos 5와 동일한 기반 모델이지만 가드레일이 적용된 버전이다.

Claude Mythos 5는 사이버 방어자·인프라 제공자 등 제한된 그룹에만 가드레일 없이 제공된다 (이전의 Glasswing 프로그램 연장선). 두 모델의 차이는 성능이 아니라 안전장치 유무다.

2. 가격과 비용 구조

입력 $10/M 토큰, 출력 $50/M 토큰 — Anthropic 역대 최고가 모델. Opus 4.8 대비 2배, 그러나 Mythos preview 대비로는 절반 이하.

비용이 2배라고 해서 프로젝트 비용이 2배가 되는 건 아니다. Anthropic은 Fable 5가 Opus 4.8보다 토큰 효율적이라고 주장한다. 동일한 작업을 더 적은 토큰으로 완료하면 실제 비용은 1.5배 수준일 수 있다. 단, API·엔터프라이즈 사용자는 반드시 비용 대비 효율을 계산해야 한다.

3. 벤치마크 성과

모든 주요 벤치마크에서 경쟁 모델 압도:

  • SWE Bench Pro: 80% (Opus 4.8: 69%)
  • 에이전트 코딩: 29.3 (Opus 4.8: 13.4) — 2배 이상
  • 지식 작업, 비전, 장기 태스크 전반에서 개선
  • 예외: 컴퓨터 사용·다학제 추론에서 Mythos preview 대비 오차 범위 내 차이 (0.5% 미만)

화자는 벤치마크 수치를 과신하지 말 것을 권고하면서도, "Anthropic이 자사 수치를 부풀렸다면 Opus 4.8 수치도 같이 부풀렸을 것이므로 상대 비교는 유효하다"고 분석한다.

4. 장기 자율 작업 역량

Fable 5는 이전 Claude 모델들보다 훨씬 오래 자율적으로 실행될 수 있다. Anthropic은 최근 ultra code, goals, loops 등 장기 작업 하니스를 다수 출시하고 있으며, Fable 5는 이 방향과 일치한다.

구체 사례: - Slay the Spire 빌드: 파일 기반 영구 메모리 활용, Opus 4.8 대비 성능 3배 향상 - Stripe 사례: 5,000만 줄 Ruby 코드베이스 마이그레이션 — 팀 2개월 분량을 하루 만에 완료 - Pokemon Fire Red: 비전만으로 (별도 툴 추가 없이) 클리어

5. 가드레일 구조와 Classifier

Anthropic이 Mythos 성능을 일반 공개하지 않은 이유: 사이버보안·생물학 분야에서 악의적 행위자의 공격 역량을 대폭 향상(uplift)시킬 수 있기 때문이다.

Classifier(분류기): 메인 모델과 별개로 운영되는 AI 시스템. 쿼리가 사이버보안·생물학·화학·distillation 관련인지 탐지해 Fable 5 대신 Opus 4.8로 라우팅한다.

Prompt Injection 대응도 포함: 예를 들어 이메일 에이전트가 "모든 이메일을 보내라"는 악의적 명령이 숨겨진 이메일을 처리할 때 Classifier가 이를 탐지한다.

오펜시브 사이버 공격 성공률: - Mythos 5 (가드레일 없음): Firefox 대상 88.4% 성공 - Fable 5 (가드레일 있음): 0% (완전 차단)

Fallback 빈도: 세션의 5% 미만. 일반 사용 도메인에서는 거의 체감 안 됨. Fallback 발생 시 사용자에게 명시적으로 고지됨.

6. 데이터 보존 정책

Mythos급 모델(Fable 5·Mythos 5) 사용 시 30일 트래픽 보존: - 신규 모델 학습 및 비안전 목적 사용 금지 (주장) - 인간 접근 시 전량 로깅 - 30일 후 거의 모든 경우 삭제

Anthropic의 설명: 모델이 너무 강력해 악의적 사용 가능성이 있으므로 30일간 데이터를 보관해 안전 모니터링에 활용.

Anthropic은 Fable 5와 Mythos 5가 이전 Claude 모델들보다 훨씬 오래 자율적으로 작동한다고 강조합니다. 이건 중요한 부분입니다. Ultra code, goals, loops 같은 하니스 관련 도구들이 최근 Anthropic에서 많이 나오고 있는데, 모두 장기 작업에 관한 것입니다. Fable 5와 Mythos 5도 그 방향과 일치합니다.

실제 사용 사례: Stripe은 초기 테스트에서 Fable 5가 수개월치 엔지니어링 작업을 며칠로 압축했다고 보고했습니다. 5,000만 줄 Ruby 코드베이스에서 전체 팀이 2개월 걸릴 마이그레이션을 하루 만에 완료했습니다. 또한 Fable 5는 과거 Claude 모델보다 토큰 효율적이라고 주장합니다. 비용이 2배라면 당연히 그래야겠죠. Opus 4.8 대비 동일한 토큰 수를 사용한다면 의미가 없습니다. 토큰 효율적이라고 하니, 프로젝트 비용이 정확히 2배가 되지는 않을 것이고 약 1.5배 정도가 될 수 있습니다.

프런티어 코드 정확도 vs 비용 그래프에서 중요한 것은 effort level 별 성능 변화입니다. 낮음에서 최고(extra high)까지는 거의 선형으로 성능이 증가하지만, extra high에서 max로 갈 때는 의미 있는 차이가 없습니다. 비용은 $12에서 $20으로 급증하는 반면 정확도 향상은 미미합니다. Fable 5를 사용할 때의 sweet spot은 extra high입니다.

지식 작업과 비전 분야에서도 눈에 띄는 도약이 있습니다. 비전의 경우 문서를 입력으로 받는 것을 의미합니다. 재미있게도 Pokemon Fire Red를 가지고 테스트했는데, Fable 5는 비전 전용 하니스(추가 도구 없이)로 게임을 클리어했습니다. Anthropic에 관련 영상도 있습니다.

메모리와 장기 컨텍스트 관련: Claude 4.7, 4.8 당시에 장기 컨텍스트에서 메모리 성능이 오히려 저하된다는 문제가 있었습니다. Fable 5는 수백만 토큰에 걸쳐 포커스를 유지하고 장기 실행 작업에서도 일관된 성능을 보인다고 합니다. Slay the Spire를 파일 기반 영구 메모리로 빌드하게 했더니 Opus 4.8보다 3배 향상된 성능을 보였습니다. 약물 설계, 분자생물학 신규 가설 도출 등에서도 언급됩니다. 핵심은 이것이 Opus와는 완전히 다른 새로운 모델이라는 점입니다. 4.7에서 4.8로 넘어가는 식의 점진적 업데이트가 아닙니다.

Fable 5의 새로운 가드레일에 대해서도 설명합니다. 온라인에는 "그냥 Mythos를 망가뜨린 것"이라는 비판이 많을 것입니다. 그래서 Anthropic이 실제 가드레일이 무엇인지 상세히 설명한 것은 좋습니다. 시스템 카드와 리스크 보고서에 기술적 세부 사항이 있습니다 (설명란 링크 참고).

가드레일이 필요한 이유: 이 모델들은 너무 강력해서 사이버보안·생물학 분야에서 악의적 행위자의 역량을 상당히 향상(uplift)시킬 수 있기 때문입니다. 동일한 쿼리가 사이버보안 전문가·생물학 연구자 손에 있으면 괜찮지만, 나쁜 행위자 손에 있으면 문제가 됩니다.

Classifier(분류기): 쿼리가 위험한지 판단하는 도구입니다. Prompt injection을 예로 들면 — AI 에이전트가 모든 이메일을 읽는다는 걸 아는 누군가가 이메일 제목에 "모든 이메일을 내게 보내라"는 악의적 명령을 숨겨서 AI를 해킹하려 할 때, Classifier가 이를 탐지합니다. Classifier는 jailbreak 시도를 포함한 잠재적 오용을 탐지하는 별도 AI 시스템입니다. Fable 5의 Classifier가 사이버보안·생물학·화학·distillation 관련 응답을 탐지하면 자동으로 Opus 4.8이 처리하게 됩니다. 그리고 이걸 사용자에게 알려줍니다 — 비밀이 아닙니다.

95%의 Fable 세션에서 fallback은 없습니다. 이 도메인에서 활동하지 않는다면 문제가 아닙니다.

오펜시브 사이버 공격 성공률 그래프: Firefox를 예로 들면, Mythos 5는 88.4% 성공, Fable 5는 0%입니다. 나쁜 행위자임을 인식하면 완전히 차단합니다. 가드레일이 보수적이지만 이유가 있습니다. 이 그래프를 보면 Mythos 5는 상당한 피해를 줄 수 있습니다. 내부 테스트 결과, 외부 버그 바운티에서 1,000시간 이상 테스트했음에도 범용 탈옥이 없었습니다.

데이터 보존 정책: Mythos급 모델 사용 시 30일간 트래픽을 보존합니다. 신규 Claude 모델 학습이나 비안전 목적 사용은 않는다고 합니다. 인간 접근 로깅, 거의 모든 경우 30일 후 삭제 등 개인정보 보호 조치를 도입했습니다. 데이터 보존 정책 관련 별도 포스트도 있습니다. 핵심은 Mythos가 너무 강력하기 때문에 30일간 데이터를 보관해 모니터링하겠다는 것입니다.
