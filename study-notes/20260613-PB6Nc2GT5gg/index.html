1. Fable 5 모델 개요 — 알아야 할 4가지

Anthropic이 "mythos급" 최상위 모델을 일반 공개했다. 이름은 Fable 5. 기존 Haiku → Sonnet → Opus 3단계 위에 4번째 레이어를 추가한 것으로, 원래 4월에 사이버보안 파트너에게만 공개된 mythos 모델을 사이버보안 오용 방지 필터를 추가해 일반 공개한 버전이다.

항목 수치
Input 비용 $10 / 백만 토큰
Output 비용 $50 / 백만 토큰
Opus 4.8 대비 2배 비쌈
구독 포함 기간 ~2026-06-22 (Pro/Max/Team/Enterprise)
이후 usage credits 별도 구매 필요

화자의 판단: 벤치마크는 참고만 하되, 실제 사용 패턴으로 직접 검증해야 한다.

2. 테스트 1 — 원샷 탑다운 슈터 게임

프롬프트 요지: 탑다운 슈터 게임, HTML 파일 1개, 이동·사격·적·다양한 무기, 시각적으로 살아있게.

모델 결과
Opus 4.8 작동함, 복셀 캐릭터·다양한 적·무기 포함, 기능적으로 합격
Fable 5 대시 기동, 사운드 이펙트, 그리드 글로우 폴리싱, "wrecked" 게임오버 이펙트 — 체감 품질 크게 위
GPT-5.5 Codex "Vox Rush" 작동, 기능 OK, 사운드 없음, 폴리시 현저히 낮음

결론: Fable 5가 명확한 우위. 원샷 게임 제작에는 Fable 5가 표준.

3. 테스트 2 — 브라우저 3D 탐험 월드

프롬프트 요지: 마법학교 성을 탐험하는 3D 브라우저 게임, 홀·계단·마법 주문 동작.

화자는 command loop 를 추가 — 모델이 성 전체를 스스로 걸어다니며 검증하도록 강제. Fable 5는 약 30~40분간 브라우저를 자율 제어하며 테스트했다.

  • Fable 5 (Castle of Whispers): Lumos(조명), Leviosa(부양) 주문 실제 동작, 숨겨진 문 열기, 초상화 SVG 포함. 합격.
  • Opus 4.8: 주문이 실행은 되지만 Lumos 후 어둠 유지, Wingardium Leviosa 부양 안 됨, 일부 구역 접근 불가 지형 오류. 불합격.

결론: 다수 기능 검증이 필요한 앱·게임이라면 Fable 5가 확실한 선택.

4. 테스트 3 — AI SaaS 랜딩페이지

프롬프트 요지: AI 클라이언트 커뮤니케이션 툴 "Rover"의 랜딩페이지, HTML 1개, 최고 수준의 디자인.

  • Opus 4.8 vs Fable 5: Fable 5가 약 10~15% 낫지만, 둘 다 퍼플 그라디언트·AI 티 여전. 수동 검수 필수.
  • Fable 5의 차별점: 인박스 뷰 컴포넌트 자체 추가, 기능 섹션·증언·가격 페이지 구성 더 자연스러움.
  • Codex: 이미지 자동 생성 가능, 덜 템플릿화된 느낌, 디자인 개선 여지 많음.

핵심 교훈: 아무리 좋은 모델도 디자인 판단 작업에서는 사람 취향+검수가 필수다.

화자는 자체 디자인 시스템을 별도 적용해 합리적인 전문가 수준 랜딩페이지를 만들 수 있었다. codex.com·Robo Nuggets 커뮤니티 홍보 포함.

5. 테스트 4 — 세일즈 대시보드

프롬프트 요지: 세일즈 CSV 데이터로 대시보드, 카드·차트·사이드바, 클라이언트에게 팔 수 있는 수준.

결론: 대시보드는 Fable 5가 클라이언트 납품 수준에 훨씬 가깝다.

6. 테스트 5 — 무드 저널 앱

프롬프트 요지: 감정 선택 + 하루 한 줄 기록 + 과거 기록 보존, HTML 1개.

  • Fable 5: 감정별 아이콘, 달·감정 아이콘 시각화, 최근 12주 그리드뷰, 인터랙션 완성도 높음.
  • Opus 4.8: 달력 뷰, 기능적으로 작동, 스타일 차이 있음.
  • Codex: 라이트모드 기본 폰트, 작동하지만 Fable 5 대비 낮음.

결론: Fable 5 우위. Opus가 달력뷰를 선택한 것처럼 UX 방향은 다를 수 있음.

7. 테스트 6 — 뮤직 비주얼라이저

프롬프트 요지: 소리에 맞춰 도형과 색이 반응하는 비주얼라이저, 시각적으로 강렬하게.

  • Opus 4.8: 퍼플 그라디언트 기본값, 여러 시각화 옵션 제공.
  • Fable 5: 미니멀 디자인("Pick a sound source, then sit back"), 드래그앤드롭 오디오 파일 지원, 팔레트 색상 변경, 풀스크린 가능. 다만 시각화 옵션 선택 없음.
  • Codex: 시각화 옵션 버튼은 있지만 실제로 변환이 안 됨 (버그).

결론: 디자인·기능 완성도는 Fable 5, 옵션 다양성은 Opus.

Anthropic의 첫 번째 mythos급 모델이 나왔습니다. 이름은 Fable 5입니다. 오늘 아침 6가지 테스트를 진행해, 토큰 사용량 2배가 정말 가치 있는지 확인해봤습니다. Opus 4.8과 GPT-5.5와 비교했고, 이 모델이 열어주는 새로운 가능성을 실제로 발견했습니다.

먼저 알아야 할 4가지를 짚어드리겠습니다.

첫째, Anthropic이 이 모델을 "일반 사용에 안전한 mythos급 모델"로 설명하고 있습니다. 주석을 보면 mythos급 모델은 Opus 위에 위치한 Claude 모델 티어라고 나와 있습니다. 기존에 Haiku, Sonnet, Opus의 3단계가 있었다면, 이제 4번째 레이어가 생긴 셈입니다.

둘째, 몇 주 전에 4월에 사이버보안 파트너 한정으로 공개됐던 mythos 모델을 리브랜딩해서 Fable 5로 일반 공개했습니다. 두 모델의 차이는 Fable은 사이버보안 오용 시도를 감지해 거부한다는 점입니다. 벤치마크는 4월 미리보기보다 소폭 개선됐습니다. 직접 확인해보세요. 다만 벤치마크는 참고 정도로만 — 우리 각자 사용 방식이 다르니까요.

셋째, Fable 5는 가장 강력하지만 가장 비싼 모델이기도 합니다. 입력 $10/백만 토큰, 출력 $50/백만 토큰으로 Opus의 2배 비용입니다. Max 플랜이 아니라면 신중하게 사용해야 합니다.

넷째, Fable 5는 6월 22일까지만 구독에 포함됩니다. 즉 지금부터 12~13일 남았습니다. Anthropic 공지에 따르면 그 이후로는 usage credits(종량제 충전) 방식으로만 사용 가능하다고 합니다. Pro, Max, Team, Enterprise 플랜에 포함된 기간이 6월 22일까지이고, 6월 23일부터는 구독 외 추가 충전이 필요합니다.

자, 그럼 이 모델이 실제로 어떻게 동작하는지 6가지 테스트로 확인해보겠습니다. 비교 대상은 Opus 4.8, 그리고 시장에서 가장 인기 있는 모델 중 하나인 GPT-5.5(Codex)입니다.

테스트 1 — 원샷 탑다운 슈터 게임

프롬프트: "탑다운 슈터 게임을 만들어줘. HTML 파일 하나, 브라우저에서 바로 열리게. 이동과 사격, 적, 기본 게임 기능 포함. 조명·깊이·시각 효과를 최대한 살려서." 결과를 비교해봤습니다.

Opus 4.8은 꽤 잘 만들었습니다. 복셀 캐릭터, 다양한 적, 다양한 무기가 포함돼 기능적으로 문제없었습니다. 꽤 좋은 기준선입니다.

Fable 5는 달랐습니다. 전체적인 룩앤필이 훨씬 완성도 있고, 사운드 이펙트도 훨씬 뛰어났습니다. 그리드 사이의 글로우 효과도 더 정교합니다. 대시 기동도 가능하고요. 맞았을 때 이펙트도 훨씬 세련됐고, 게임 오버 시 "wrecked" 메시지가 뜹니다. 이게 단 하나의 프롬프트에서 나온 결과입니다. 정말 제대로 된 게임이라고 할 수 있습니다.

Codex(GPT-5.5)는 "Vox Rush"라는 이름의 게임을 만들었습니다. 기능은 작동하지만 사운드 이펙트가 없고, Fable 5의 완성도와 비교하면 훨씬 아래입니다. 원샷 게임에서는 Fable 5가 표준을 세웠다고 할 수 있습니다.

테스트 2 — 브라우저 3D 탐험 월드 (마법학교)

프롬프트: "학생이 마법학교 성을 탐험하는 브라우저 3D 체험. 홀을 걷고, 계단을 오르고, 마법 주문 여러 개가 실제로 작동해야 함." 여기서 저는 command loop를 추가로 지시했습니다 — 모델이 성 전체를 직접 걸어다니며 모든 것이 검증됐는지 확인하도록. 이 테스트는 30~40분 동안 실행됐고, 모델이 직접 브라우저를 열어 게임을 테스트하는 모습이 꽤 인상적이었습니다.

Fable 5 결과: "Castle of Whispers"라는 이름의 3D 성. 들어가면 "성을 탐험하세요. 그레이트홀은 동쪽, 탑 계단은 북쪽"이라는 안내가 나옵니다. Lumos 주문을 입력하면 지팡이로 조명이 켜지고, Leviosa를 입력하면 물체가 부양합니다. 숨겨진 문도 열립니다. 단일 프롬프트와 몇 분 작업으로 이 전체 3D 환경을 만들었습니다. 그래픽이 최상은 아니지만, 로컬에서 실행되는 것치고는 상당한 퀄리티입니다.

Opus 4.8 결과: 방식은 비슷하지만 주문이 실제로 작동하지 않습니다. Lumos 후에도 여전히 어둡고, Wingardium Leviosa도 부양이 되지 않았습니다. 건너갈 수 없는 구역이 있는데도 자체 검증이 되지 않았습니다. Opus 4.8은 이 테스트를 통과하지 못했습니다.

여러 기능을 검증해야 하는 앱이나 게임이라면 Fable 5가 확실히 한 단계 위입니다.

테스트 3 — AI SaaS 랜딩페이지

프롬프트: "'Rover'라는 AI 툴의 풀 랜딩페이지, HTML 파일 하나. 이 소프트웨어는 에이전시와 서비스 비즈니스의 클라이언트 커뮤니케이션을 처리하는 AI 오퍼레이터입니다. 디자인을 최대한 잘 만들어줘."

결과는 솔직히 아쉬웠습니다. Opus 4.8과 Fable 5 모두를 봤는데, 아무리 mythos급 모델이라도 AI가 만든 티를 완전히 피하지는 못했습니다. Fable 5가 약 10~15% 낫지만, 두 결과물 모두 퍼플 그라디언트가 남아있고 태그라인도 워크샵이 더 필요한 수준입니다.

그래도 Fable 5가 개선된 점: 인박스 뷰 컴포넌트가 자연스럽게 포함됐고, 기능 섹션·절차·증언·가격 페이지 구성이 더 적절합니다.

Codex 결과는 이미지 자동 생성이 가능하고, 덜 템플릿화된 느낌이지만 디자인 완성도는 여전히 갈 길이 멉니다.

저는 자체 디자인 시스템을 적용해 더 전문적인 랜딩페이지를 만들 수 있었습니다. 이런 내용을 더 배우고 싶다면 Robo Nuggets 커뮤니티에서 다루고 있습니다(링크 참조).

테스트 4 — 세일즈 대시보드

Opus와 Fable에게 세일즈 CSV 데이터로 대시보드를 만들라고 했습니다. 카드, 차트, 사이드바 포함, 실제 클라이언트에게 팔 수 있는 수준으로.

Opus 4.8: 예상대로 한 번에 보라색 vibe코드 티가 납니다. 그리고 항상 보이는 문제 — 데이터 제목 텍스트가 심하게 오프센터입니다. 엔터프라이즈 납품에는 용납할 수 없는 수준이에요. 데이터 정확성은 오프라인 검증 결과 맞았지만, 이런 정렬 문제를 잡으려면 추가 가이딩이 필요합니다.

Fable 5: 디자인과 폰트는 취향에 따라 더 개선할 수 있지만, 기본적으로 모든 텍스트가 제대로 정렬돼 있고 전반적으로 더 전문적입니다. 그리고 프롬프트에 요청하지 않았는데도 PDF 내보내기 기능을 자체적으로 추가했습니다. 대시보드라는 걸 파악하고, 클라이언트에게 주간·월간 리포트를 보내야 할 것이라고 판단한 것입니다. 실제로 내보낸 PDF 레이아웃도 깔끔하게 잡혀 있어 클라이언트에게 바로 보낼 수 있는 수준입니다.

테스트 5 — 무드 저널 앱

프롬프트: "무드 저널 앱, HTML 파일 하나. 현재 감정을 선택하고 하루에 한 줄 메모. 과거 기록이 재방문 시 유지돼야 함."

Opus 4.8: 달력 뷰, 기능은 작동합니다.

Fable 5: 보기 좋은 감정 아이콘, 달 아이콘, 로그된 날 목록, 아이콘 클릭 인터랙션이 잘 작동, 최근 12주 그리드뷰 포함. 전반적으로 더 완성도 있습니다.

Codex: 라이트모드 기본 폰트와 스타일, 작동은 하지만 Fable 5에 비해 훨씬 아래입니다. Anthropic에 박수를 보냅니다.

테스트 6 — 뮤직 비주얼라이저

프롬프트: "소리에 맞춰 도형과 색이 춤추는 뮤직 비주얼라이저, 시각적으로 최대한 강렬하게."

Opus 4.8: 파란색·보라색 그라디언트 기본값. 여러 시각화 옵션 제공.

Fable 5: 미니멀 디자인. "Pick a sound source, then sit back"이라는 안내. 오디오 파일을 드래그앤드롭하면 실제로 재생되며 비주얼이 반응합니다. 팔레트 색상 변경, 풀스크린 가능. 다만 복수 시각화 옵션은 없습니다.

Codex: 시각화 옵션 버튼은 있지만 실제로 비주얼이 변경되지 않는 버그가 있습니다.

최종 정리

첫째, Fable 5는 Opus 4.8 대비 확실히 큰 발전입니다. 제대로 완성해야 할 때, 최고 수준이 필요할 때는 비용과 토큰을 쓸 가치가 있습니다. 많은 테스트에서 Fable 5가 단순히 보라색 그라디언트를 기본값으로 내뱉는 것이 아니라, 받은 브리프에 취향을 적용하기 시작했습니다.

단, 사용 목적에 따라 다릅니다. 랜딩페이지 테스트처럼 모델을 완전히 믿으면 AI 티가 여전히 남습니다. 이 모델들에서 항상 맞는 조합은 사람의 취향과 판단을 더해 모델 출력을 훨씬 나은 결과물로 발전시키는 것입니다.
